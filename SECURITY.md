# MyGPR Security and Data-Safety Policy

MyGPR processes engineering survey data that may contain sensitive locations.
Do not attach raw project data to public issue trackers. Use the diagnostics-only
support bundle, which excludes `raw/`, `processed/`, source files, and raster
content by design.

Report suspected data-loss, path-traversal, project-lock, package-signing, or
supply-chain issues privately to the project maintainer. Include the MyGPR
version, diagnostic ID, support bundle, and reproduction steps. Do not include
credentials or precise field coordinates unless explicitly authorized.

Supported production branches receive fixes. Research and compatibility modules
are not production security boundaries.
