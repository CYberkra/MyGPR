# MyGPR v0.9.28 Live Canvas V1.3 实施报告

日期：2026-07-14

## 1. 本轮目标

在不改变 Golden Reference V1.2 五页外观基线的前提下，将核心专业主视图区从静态参考图适配器替换为真实数据渲染与联动组件。

## 2. 已完成内容

### 项目管理
- 工区概览由静态图片替换为实时项目空间图。
- 项目切换、测线选择与地图刷新保持联动。

### 测线处理
- 主 B-scan 使用当前 `GPRDataSet` 实时渲染。
- A-scan 与频谱根据当前道实时计算。
- 鼠标移动和点击可更新当前道、距离、双程走时和振幅信息。
- 处理结果刷新后同步更新主图和分析图。

### 界面标注
- 主 B-scan 使用真实处理/原始数据渲染。
- 基覆界面曲线、控制点、弱可见区段与 no-pick 语义实时绘制。
- A-scan、局部放大、路径趋势和可见性统计均由当前标注实时生成。
- 标题区同步当前测线、显示来源、绑定版本、标注版本和状态。

### 空间成果
- 平面成果使用真实轨迹、界面曲线和当前项目坐标数据绘制。
- 剖面成果使用真实地表高程与界面高程数据绘制。
- 地图点击可选择最近测线，并刷新关联剖面。
- 平面、剖面和 DEM 分析画布均为实时 Matplotlib 画布。

### 成果报告
- A4 报告页面保留 Golden Reference 布局。
- 报告中的空间图和高程剖面改为实时项目数据渲染。
- 项目或当前测线变化后可重新刷新报告图件。

## 3. 工程性改进

- 新增 `golden_reference_styles.py`，将 Golden Reference 样式从主窗口拆出，主窗口文件重新控制在 1500 行以内。
- 演示数据种子升级为 `five_page_demo.v1.2`，补充 L06 处理结果和标注草稿。
- 新增 `test_live_canvas_v13.py`，验证五页核心主视图均为真实 FigureCanvas。
- 调整处理页和标注页画布最低高度，兼顾 1672×941 基准图与 1536×816/1280×720 窗口适配。

## 5. 当前边界

- 平面成果未内置真实卫星影像；当项目导入正射影像或 GIS 栅格后，可作为底图渲染。
- 三维成果页仍以现有三维业务组件为后续接入点，本轮主要完成平面和剖面实时化。
- 报告页已使用实时图件，但完整所见即所得分页、章节编辑和正式 PDF 版式仍需后续业务接线。
- Golden Reference 图仅作为布局与视觉基线，不再作为核心主视图内容。
