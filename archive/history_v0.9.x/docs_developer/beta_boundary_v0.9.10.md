# MyGPR v0.9.13 beta 功能边界

## 已开放

- 项目创建、打开、最近项目、项目设置。
- CSV / TXT / NPY / NPZ / H5 / HDF5 测线导入。
- 批量导入、导入预检、坏文件诊断。
- 数据质检、B-scan 方向修正、测线清单 CSV 导出、项目 ZIP 备份。
- 现场算法注册表中的测线处理方法。
- 目标标注保存和启发式辅助检测。
- 空间成果刷新、坐标导出、平面图、三维成果窗口和图层控制。
- HTML / JSON / CSV / PDF 报告包。
- 15.6 寸 1080P compact mode 和 Windows 截图诊断脚本。

## 未开放或暂缓

- 厂商原生格式完整解码：DZT、DT1/HD、OKO 等。
- Excel 报告闭环。
- PGDA-CSNet 或其他深度学习自动识别模型。
- 钻孔 / 开挖验证资料的正式关联管理。
- 研究模式 UI 作为默认页面。

## 表述边界

- 目标识别应表述为“启发式辅助检测”，不得表述为“AI 深度学习识别已接入”。
- 厂商格式在没有样例测试前不得表述为“完整原生支持”。
- PDF 当前为 beta 版报告模板，正式交付模板仍需行业版式细化。
