# Field UI 1080P Iteration

本次迭代以 15.6 英寸 1080P 笔记本为视觉基准，窗口默认尺寸调整为 1920×1080，并围绕目标稿完成以下前端推进：

- 主工作台默认使用 1920×1080 尺寸启动，最低可缩放到 1366×768。
- 优化顶部应用栏、模块导航、卡片间距、左侧项目树宽度与工作区边距，使比例更接近目标稿。
- 修复 qfluentwidgets 主题下 QLabel 出现浅灰块背景的问题，统一卡片标题栏与文本透明背景。
- 将卡片标题从可伸展布局改为固定标题栏，避免标题垂直居中导致页面失衡。
- 针对首页固定中部和底部模块高度，保证 1080P 截图首屏信息密度更稳定。
- 增强预览用 B-scan 合成纹理，使测线处理、目标定位、报告预览中的雷达剖面更接近真实 GPR 视觉效果。
- 保持现有处理后端不变，本次主要推进产品化工作台 UI 与截图验收基准。

验证：

```bash
QT_QPA_PLATFORM=offscreen ../.venv/bin/python /mnt/data/mygpr_work/capture_mygpr_1080p.py
```
