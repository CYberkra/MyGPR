# MyGPR v0.8.79 正式项目操作入口

本轮目标是把项目管理页从 demo 状态推进到可执行的用户入口。

## 已完成

- 新建项目：创建空正式项目，不自动填充 demo 测线。
- 打开项目：校验 `project.json` 和 schema 后打开。
- 导入测线数据：支持 CSV / NPY / NPZ / H5 / HDF5，归一化为 `GPRDataSet`。
- 导入 RTK/IMU：先作为轨迹证据文件附加到当前测线目录。
- 最近项目：记录到平台默认位置的 `recent_projects.json`。
- 导入格式校验：对 DZT / RD3 / DT1 等未完成原生解码的格式给出明确转换提示。

## 保持边界

- 不接入预设流程处理。
- 不把导入逻辑写死到按钮回调。
- 不假装已完整支持所有厂商二进制格式。
