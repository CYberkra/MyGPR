# MyGPR v0.8.82 项目元数据完善与项目设置入口

## 目标

在 v0.8.81 的项目向导和导入预检基础上，补齐正式工程项目需要的元数据字段，并提供可编辑的项目设置入口。

## 完成内容

- 新建项目表单补充项目编号、设备型号、坐标系统和垂向基准。
- 新增项目设置对话框，可修改核心项目元数据。
- 新增 `update_project_metadata()`，避免 GUI 直接修改 `project.json`。
- `ProjectStatusSnapshot` 增加操作员、坐标系统和垂向基准字段。
- 项目概览卡片显示真实项目元数据。

## 边界

- 不改变算法处理链路。
- 不接入预设流程处理。
- 不新增“显示与对比”主导航页。
- 坐标系统和垂向基准本轮只作为元数据保存和展示，不执行坐标转换。
