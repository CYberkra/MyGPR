# MyGPR v0.8.98 数据质检与 B-scan 方向校验

本轮新增导入后质量检查能力。

## 输出

每条已导入测线会生成：

```text
raw/<line_id>/<line_id>_quality_report.json
```

## 检查项

- B-scan 矩阵是否二维；
- 采样点数与道数是否过少；
- 时间窗与测线长度是否有效；
- 振幅范围是否近似为零；
- NaN/Inf 占比；
- 轨迹点数与 trace_count 是否匹配；
- 是否存在矩阵转置风险。

## UI 行为

项目管理页“运行数据质检”现在会执行真实项目质检，并把通过/警告/失败写回测线清单。
