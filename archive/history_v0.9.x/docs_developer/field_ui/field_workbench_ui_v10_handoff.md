# MyGPR v0.9.24 Field Workbench UI v10 交接说明

## 1. 版本目标

v10 是本轮 15.6 寸 1080P / 125% DPI 适配与界面重构的冻结版。核心目标是：

- 解决测线处理页右侧连续处理按钮重叠问题；
- 将测线处理页改为单主图 B-scan + 项目树 Step 处理链；
- 统一项目树、表格、卡片、按钮、图像坐标轴等基础视觉风格；
- 重新组织空间成果页和成果报告页，减少大面积空白；
- 提供 Step 右键交互、撤回、重置、差异对比等工程使用逻辑。

## 2. 测线处理页交互逻辑

### 2.1 单主图 B-scan

测线处理页中间只显示当前选中的 B-scan 结果。原始 B-scan 不再长期占据左半屏，而是作为处理链的 Step 00 存在。

### 2.2 项目树 Step 处理链

处理结果节点下自动维护当前测线处理链：

```text
处理结果
  L03 过路口测线 当前处理链
    00 原始 B-scan
    01 平均背景去除
    02 增益补偿
```

每次点击“执行当前步骤”：

1. 用当前 Step 数据作为输入；
2. 生成一个新的 Step；
3. 自动加入项目树；
4. 主 B-scan 自动切换到最新 Step。

“撤回一步”会删除最后一个 Step，并回到上一 Step。“重置到原始”会清空处理链，只保留 Step 00。

### 2.3 Step 右键菜单

Step 节点支持右键操作：

- 回看 Step 结果；
- 从此步继续处理；
- 与原始 / 差异图对比；
- 删除此步之后的全部步骤；
- 复制步骤摘要到剪贴板。

## 3. 处理对比弹窗

“前后对比”弹窗显示三幅图：

1. 原始 B-scan；
2. 当前步骤结果；
3. 差异图：当前结果 - 原始结果。

差异图用于快速判断当前处理步骤对剖面产生了哪些变化。

## 4. 空间成果页逻辑

空间成果页主图采用两种策略：

- 页面内预览：自适应铺满卡片，优先减少空白、提升浏览效率；
- 放大主图：保持真实工程比例，用于严格空间检查。

页面上方有提示：

```text
页面预览：自适应｜放大主图：真实比例
```

## 5. 成果报告页逻辑

成果报告页不再模拟完整 PDF 阅读器，而作为报告生成工作台：

- 左侧为封面摘要；
- 中间为章节目录；
- 右侧为当前图件预览；
- 下方为报告结构、成果检查、导出格式摘要。

真正查看 PDF 时使用“全屏预览”或“生成/打开 PDF”。

## 6. 视觉规范要点

本轮统一了以下基础风格：

- 表格：弱化网格线、固定行高、统一表头高度；
- 卡片：统一圆角、边框、背景；
- 项目树：统一行高、选中态、悬停态；
- 按钮：统一圆角、主次按钮视觉；
- 图像：弱化坐标轴、网格线、边框；
- 详情卡：统一 detailTitle / detailSubtitle / miniStatBox 风格。

## 7. 已知边界

- 沙盒截图使用 Qt offscreen，字体行高和 Windows 原生 125% DPI 可能仍有细微差异；
- 空间成果页页面预览不是严格等比例，严格比例应通过“放大主图”查看；
- 当前 Step 处理链为工程工作流，不等同于正式报告成果；报告导出时仍以当前项目状态为准。

## 8. 验收建议

在 Windows 15.6 寸 1080P / 125% DPI 下重点检查：

1. 测线处理页右侧连续处理按钮是否重叠；
2. 执行 Step 后项目树是否同步；
3. Step 右键菜单是否可用；
4. 空间成果页是否仍有明显无意义空白；
5. 成果报告页封面 / 目录 / 当前图件是否比例正常；
6. 五个工作页是否都能在 1536×816 逻辑窗口中完整显示。
