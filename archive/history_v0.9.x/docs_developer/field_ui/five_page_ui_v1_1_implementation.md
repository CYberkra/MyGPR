# MyGPR 五页 UI V1.1 实施记录

日期：2026-07-13  
基线版本：MyGPR v0.9.28  
状态：第二阶段已实施

## 1. 本轮目标

在五页 V1 视觉壳层基础上，优先把“测线选择—处理草稿—处理链编辑—跨页预览”从静态结构推进为可持续工作的业务状态，并让离屏预览稳定展示完整五页数据。

## 2. 已实施内容

### 完整演示工程

- 八条测线均生成可读取的合成 GPR 数据。
- 八条测线均生成彼此分离的 RTK/GNSS 轨迹。
- L01、L02、L03、L05、L07 生成基覆界面标注与空间曲线。
- 五条测线生成正式处理结果示例。
- 演示工程增加版本标记，重复打开时不再反复重建全部数据。

### 测线处理草稿

- 每条测线拥有独立的内存处理会话。
- 切换测线时不销毁当前处理链；切回后恢复处理步骤、当前结果和状态。
- 关闭主窗口时统一释放所有处理会话及临时映射文件。

### 中间步骤编辑与重算

- 选中已有处理步骤后，右侧自动载入该步骤方法和参数。
- 修改参数后按钮动态显示“应用从第 N 步开始的全部更改”。
- 从被编辑步骤开始重算其后全部步骤。
- 重算采用事务式替换：任一步失败或取消时保留上一次完整处理结果。
- 新增步骤仍使用“应用当前步骤”，不会覆盖原始数据。

### 处理页交互

- 顶部“添加处理步骤”已连接到处理控制舱。
- 顶部、右侧应用按钮共享同一动态文字和执行逻辑。
- 正式输出按钮统一命名为“保存为处理版本”。
- 参数控件变化会立即标记为“存在未应用更改”。
- “展开处理链”可定位到底部处理链页签。

### 可重复预览

- 截图脚本默认创建隔离运行目录，并在每次捕获前清理。
- 捕获时自动准备 L03 三步处理链，避免处理页为空。
- 五页预览均来自本轮实际运行程序，而非设计图或拼图。
