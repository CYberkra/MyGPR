# MyGPR 五页 UI V1 实施记录

日期：2026-07-13  
基线版本：MyGPR v0.9.28  
状态：第一阶段已实施

## 1. 范围

本轮以 `docs/ui_reference/five_page_v1/` 中五张确认图为视觉、结构、组件和任务拆分基线，正式主导航保持：

```text
项目管理 → 测线处理 → 界面标注 → 空间成果 → 成果报告
```

## 2. 已落地内容

### 全局壳层

- 删除常驻左侧一级导航轨，改为顶部横向五页导航。
- 每页增加独立上下文工具栏。
- 保留可跨页面运行的全局任务条，空闲时隐藏。
- 新增统一底部状态栏。
- 页面仍使用响应式工作区容器，兼容紧凑窗口。

### 项目管理

- 左侧项目树。
- 中央项目摘要、工区地图、测线清单、最近活动和项目备注。
- 右侧“项目信息 / 存储与备份”。
- 测线清单字段对齐已确认的八列工程信息。

### 测线处理

- 左侧项目与版本树。
- 中央处理工作区、处理结果和处理链。
- 右侧处理控制舱与参数页。
- 顶部采用“添加步骤 / 应用更改 / 原始对比 / 保存版本”操作路径。

### 界面标注

- 保留连续基覆界面 trace/sample 锚定工作流。
- 顶部横向标注工具栏与现有关键点、区段语义、自动辅助和版本保存逻辑接通。
- 中央 B-scan、底部证据区和右侧标注控制舱继续作为主要工作区。

### 空间成果

- 新增左侧空间成果树。
- 新增“平面成果 / 剖面成果 / 三维成果”主视图标签。
- 平面成果保留真实 GIS 地图和联动高程分析。
- 右侧改为“成果配置 / 图层 / 属性与导出”。
- 保留现有空间刷新、GIS 图层、坐标导出和三维入口。

### 成果报告

- 保留左侧报告大纲、中央文档预览、右侧报告配置和底部生成文件区域。
- 全局上下文工具栏提供模板、快照、PDF、数据表、交付包和审批入口。
