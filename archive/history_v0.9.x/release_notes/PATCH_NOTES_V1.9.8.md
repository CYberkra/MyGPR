# MyGPR v0.9.28 V1.9.8 — 正式工作台去演示化

## 变更

- 删除 `core/field_demo_store.py` 及 `FieldProjectStore.create_or_open_demo()`。
- 正式入口不再创建或打开 `runtime_projects/field_demo_project`。
- 启动状态统一为“未打开项目”，五个工作区显示正式空状态。
- 仅通过“新建项目”或“打开项目”进入工程流程。
- 删除产品 UI 中硬编码的 `GPR_2024`、固定测线、固定处理版本、固定日期、演示任务进度条和合成地图/B-scan 回退。
- 项目树、处理页和标注页改为绑定当前真实项目状态。
- 删除项目后回到真正空状态，不再回退到 `L01` 等假测线。
- 地图验收脚本改为必须显式传入真实项目路径。
- synthetic 数据生成能力仅保留在算法研究和测试范围，不再用于正式产品界面启动或无数据回退。

## 验证

- Python 全量语法编译通过：`core/`、`ui/`、`scripts/`、`tests/`。
- 与项目存储、处理产物和标注来源相关的非 Qt 回归测试：19 项通过。
- 当前容器未安装 PyQt6，因此无法在该容器内执行 Qt 窗口运行截图；已新增 Qt 回归测试，供 Windows/完整依赖环境运行。
