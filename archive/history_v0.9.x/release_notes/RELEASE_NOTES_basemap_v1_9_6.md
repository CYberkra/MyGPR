# MyGPR v0.9.28 · V1.9.6 Basemap Integration

## 功能

- 空间成果页新增真实地貌底图控制区。
- 支持天地图影像（开发者 Key）与自定义 HTTPS XYZ/WMTS 模板。
- 在线瓦片通过 Job Manager 异步加载，仅请求项目当前空间范围。
- 支持 GeoTIFF 与 MBTiles 离线影像导入。
- 测线、界面曲线、GIS 图层与在线底图按 CRS 重投影叠加。
- 地图点击定位到最近测线和雷达道，并同步处理/标注游标。

## 可靠性与边界

- 自定义地图服务按 URL 指纹隔离缓存，避免切换服务后串图。
- 缓存带时效和 512 MiB 全局容量回收。
- 单次视图最多 64 张瓦片，单瓦片响应最大 8 MiB。
- 非本机服务强制 HTTPS；在线底图不用于批量预取或制作离线包。
- 项目坐标系缺失且坐标并非经纬度时拒绝叠加，避免错位展示。

## Windows 启动器

- 启动器明确要求 Python 3.11–3.13。
- 依赖完整但版本过低的 Python 3.10 不再被误选。
- 启动日志会列出候选解释器版本与缺失条件。

## 兼容性

- 不修改原始 GPR、标注、空间成果或报告数据格式。
- 不依赖奥维客户端；KML/KMZ 等外部协作仍可作为后续可选扩展。
