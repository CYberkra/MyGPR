# MyGPR v0.9.28 · V1.9.9 前后端闭环修复

本轮以 V1.9.8 去演示化源码为基础，修复正式五页工作台中“界面存在但功能未闭环”和“后端能力未暴露”的问题。产品版本仍为 v0.9.28 beta，V1.9.9 是本轮源码交付迭代号。

## 正式工作台修复

- 项目管理：接通测线搜索、状态筛选、全部真实测线展示和持久化项目备注；删除固定 CRS 演示值，EPSG 与中央经线从项目坐标系实时解析。
- 测线处理：显示平移/缩放/复位、振幅模式、色标与方法分类快捷入口真实生效；暴露等距道重采样；接入 AutoTune 参数推荐；支持保存和重新执行处理链模板。
- 界面标注：接通控制点约束辅助追踪、整线追踪、区段拆分/删除/边界调整、属性写回、撤销/重做、截图、自动保存和提交复核；未接入训练模型时不再显示“模型预测”伪功能。
- 空间成果：接通图层透明度、可信度/深度过滤、距离测量、截图和真实重绘；增加 UAV 三维地理参考导出，生成 VTK、CSV、JSON 与 PNG 预览。
- 成果报告：移除固定页码、固定资源数量和 GPR_2024 残留；读取实际 PDF 页数、图件、表格和交付目录；报告打开、目录打开和生成动作连接真实服务。
- 全局任务条：“取消”现在取消当前可取消任务，不再错误打开任务中心。

## 模式与兼容层

- 默认正式模式仅显示项目管理、测线处理、界面标注、空间成果、成果报告五页。
- 研究模式由 `MYGPR_PRODUCT_MODE=research` 显式启用，并增加可执行的仿真验证页。
- 旧项目入口改为 `open_legacy_project()`；兼容 `open_project()` 会先识别正式 `project.json`，避免误查旧 manifest。

## 验证

- `core/`、`ui/`、`scripts/`、`tests/` 全量语法编译通过。
- 正式桌面相关去重回归：503 项通过。
- 覆盖项目/任务/模式、处理与工作流、AutoTune、导入与同步、标注、空间、UAV 三维、报告、静态回调、复杂度与发布门禁。
- 未把耗时的独立科研 Runner 纳入本轮桌面发布回归；它们不属于正式五页 GUI 的功能闭环。

## 明确边界

- PGDA-CSNet/路径拾取训练模型尚未接入；自动判读目前是基于振幅包络、连续性和人工锚点的确定性辅助追踪，结果必须人工复核。
- 正式报告仍由后端固定交付合同统一生成 PDF/HTML/XLSX/CSV/JSON，不提供任意格式组合编辑器。
- Windows 11 真机 DPI、系统字体、GPU/OpenGL 和厂商原始格式仍需在目标设备执行发布候选验收。
