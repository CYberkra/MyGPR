# MyGPR v0.9.28 Module Linkage V1.8

日期：2026-07-14

## 目标

在不改变已冻结五页视觉结构的前提下，完成项目管理、测线处理、界面标注、空间成果与成果报告之间的工程对象联动、状态传递和关闭重开恢复。

## 已完成

- 新增项目级 `mygpr.workspace_context.v1`，持久化当前页面、测线、处理来源、标注版本、空间成果和报告版本。
- 页面跳转不再只是切换标签，而是携带明确的测线和成果版本。
- 测线处理保存后，界面标注自动绑定对应处理产物。
- 标注保存或确认后，空间成果和报告自动标记为需要更新。
- 空间成果刷新后，空间页状态清除，报告页保持待更新。
- 正式报告生成后，完整下游 dirty 状态闭环清除。
- 顶部五页导航使用非阻塞圆点提示过期模块，并在提示中显示原因。
- 各页新增明确的联动动作：`进入标注`、`进入空间`、`用于报告`、`查看空间来源`。
- 当前测线、处理来源、空间成果和报告版本可在关闭项目并重新打开后恢复。
- 事件刷新限定到受影响模块，避免每次操作无差别重建五个页面。

## 数据与兼容性

- 新增 schema：`mygpr.workspace_context.v1`。
- 新增可复现联动证据 schema：`mygpr.module_linkage_evidence.v1`。
- 旧项目没有工作区上下文时自动创建安全默认文件，不改变既有处理、标注、空间和报告成果。
- 旧 TARGETS 事件继续兼容；正式页面使用语义更明确的 annotation 事件。
