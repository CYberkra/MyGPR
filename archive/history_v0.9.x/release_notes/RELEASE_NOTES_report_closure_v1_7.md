# MyGPR v0.9.28 Report Closure V1.7

## 目标

将成果报告页从实时项目预览和一次性报告导出，升级为正式、不可变、可追溯的报告快照与交付包版本。

## 新增

- `mygpr.report_version_index.v1` 正式报告版本索引。
- 不可变 `report_vNNN` 报告版本与当前版本选择。
- 项目数据修订、空间成果版本、模板版本和软件版本的快照绑定。
- 绑定空间成果的完整副本、来源 SHA-256 与过期检测。
- PDF、HTML、XLSX、CSV/JSON 表、工程图件、审计表和校验清单。
- `report_seal.json` 报告封印与完整性验证。
- 独立正式交付 ZIP 及 ZIP SHA-256 旁车文件。
- 编制、复核、批准人员和审签状态冻结。
- 事务 staging、取消清理和旧版本不可覆盖。

## UI

- 成果报告页显示当前报告版本、项目快照、空间成果版本和是否过期。
- “生成新报告版本”创建新的不可变版本。
- “打开当前交付包”直接定位正式 ZIP。
- 报告来源变化时使用非阻塞风险提示，不静默替换旧报告内容。

## 兼容性

- 旧 `latest_report_manifest.json` 与原有报告生成接口继续保留。
- 主产品版本仍为 v0.9.28，本文件描述五页业务增量 V1.7。
