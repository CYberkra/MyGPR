# MyGPR v0.9.26 现场生产系统重构说明

发布日期：2026-07-13

本版本在 v0.9.25 基础上完成五类生产化改造，项目数据结构保持向后兼容。

## 1. 统一后台任务系统

- 新增 `core/job_manager.py` 与 `ui/job_manager.py`，统一任务状态、进度、取消、失败诊断和历史记录。
- 单步/批量处理、大文件导入预检与导入、测线方向修正、源文件校验与重定位、项目维护、空间导出、GIS 制图、标注保存/导出、正式报告生成均通过 Job Manager 执行。
- 核心操作采用协作式取消；提交前使用临时文件或 staging，取消/失败不替换既有正式成果。
- 大文件预检改为头信息或有限抽样，避免在主线程完整读取多 GB 数据。

## 2. 雷达—RTK—IMU—飞高同步

- 雷达道时间戳作为主时间轴，RTK、IMU、飞高流分别配置时间偏移与触发延迟。
- 支持最大时间残差、禁止静默外推、RTK 固定解比例、覆盖率、缺口、跳点和同步警告。
- 支持项目 CRS 转换、GNSS—雷达天线杆臂改正，以及逐道位置/姿态/质量元数据。
- 同步结果保存为轨迹 CSV、逐道元数据和同步清单，可被空间成果与报告直接引用。

## 3. 真实离线 GIS 空间成果

- 空间页移除装饰性假底图和轨迹高程平铺的伪 DEM。
- 支持 GeoTIFF/DEM、GeoJSON、KML、Shapefile、GeoPackage 和坐标 CSV 图层。
- 图层登记 CRS、范围、角色、可见性与透明度，并按项目坐标系重投影叠加。
- 新增无头正式制图事务，可后台输出 PNG/PDF/SVG，包含测线、基覆界面、指北针、比例尺和 CRS 信息。
- 图层导入与空间成果导出支持取消、回滚和原成果保护。

## 4. 人工标注工作站增强

- B-scan 改为 mmap 视窗切片与分块原分辨率加载，放大时不再依赖整幅缩略图。
- 增加当前道 A-scan、局部证据放大、关键点导航、快捷键、整体平移和稳健平滑。
- 增加恢复草稿自动保存；正式保存和训练标签导出进入后台任务系统。
- 标签继续锚定原始 trace/sample，保持连续基覆界面、弱可见、忽略和无界面语义。

## 5. 正式行业报告链

- 报告包升级为 `mygpr.report_package.v3`。
- 生成 PDF、HTML、Excel、标准化 CSV/JSON、工程图件、文件审计和 `checksums.sha256`。
- 增加编制/复核/批准、报告版本、同步质检、GIS 图层、处理结果哈希、连续界面统计和历史点目标附录。
- 正式平面图由真实 GIS 图层与项目空间成果生成，不再使用相对坐标示意底图。
- 报告生成在后台执行；取消或失败不会登记为最新正式成果。

## 验证结果

- Python 编译检查通过。
- 版本一致性检查通过：`0.9.26`。
- 60 项无头回归测试通过，覆盖新增模块、事务取消/回滚和旧项目兼容。
- 当前构建环境为 Linux，未安装 PyQt6/qfluentwidgets/PyWavelets，因此未在本环境执行 GUI 启动、Windows 125%/150% DPI 和真实设备/多 GB 数据实机验收。
- Linux 缺少中文字体时，Matplotlib 会报告 CJK 字形警告；文件仍可生成。Windows 正式环境应安装并使用微软雅黑或思源黑体等中文字体。

## 正式现场验收建议

在目标 Windows 勘探电脑上完成：

1. 安装 `requirements.txt` 全部依赖并运行 `python scripts/check_env.py --strict`。
2. 使用真实雷达、RTK、IMU、飞高文件验证时间基准、杆臂和 CRS。
3. 使用至少一条多 GB 测线测试导入、取消、处理、标注、GIS 和报告闭环。
4. 在 100%、125%、150% 缩放及不同分辨率下检查所有页面。
5. 校验 PDF/Excel、GIS 坐标、SHA-256 清单和项目恢复备份。
