# MyGPR 一致性维护验收记录 · 2026-10-23

范围：MyGPR 0.11.2 工作区的五项审查问题，以及复杂度、维护预算门禁。基础提交 e379a5ef602459fef166539f96d3904e7cd9f76a；保留此前工作区改动，修复列入 Unreleased。

## 修复与回归

- 导入失败或取消：新测线不残留索引，替换测线恢复旧矩阵、复制来源、元数据、项目清单和目录记录。NPY 成功、异常路径均显式关闭 mmap。
- 保存处理成果失败：矩阵、参数、清单、最新参数、成果指针和分支头作为整体回滚，包含最后一次项目清单写入失败。
- 批量删除失败：全部选择及其依赖成果一同回滚；覆盖第二个文件移动失败、目录写入失败、清单失败和 Windows 真实 HDF5 文件占用。
- 文件快照采用有界复制；未变动文件在恢复时不做无谓替换。嵌套项目清单保存复用外层事务。
- 同一 SQLite 事务内的提交标记决定文件日志恢复方向；子进程在 SQLite 提交前后及第二次嵌套清单写入处退出，重开结果均一致。恢复日志的路径、备份先完整校验，拒绝项目根与事务恢复目录。
- 时间基准优先显式 dt，遵循 time_axis_endpoint；未标记的旧头保留 N-bin 合同。裁剪保留采样间隔、时间偏移及单点零跨度，精确边界仅在 8 ULP 内吸附整数，近边界值保持原语义。
- Hybrid 与 Legacy 成果保存、重开、续接均保留 dt/零跨度；旧存储写入进度通过统一适配器转换。
- 交互工作台保存当前输出采样头。导入轨迹和 ICZT 参数验证拆分为独立阶段，未修改门禁阈值或放宽协调器限制。

新增行为回归集中于 `tests/test_project_mutation_atomicity.py`（32 项）；相邻断言按完整回滚及半开区间的采样间隔守恒更新，未删除失败检查。

## 验证结果

- 完整常规回归：2205 通过，7 跳过，1 未纳入；0 失败、0 错误。
- 9 项门禁通过：编译、架构、schema、版本、发行卫生、后端接口、格式兼容、复杂度、维护预算。
- 修改文件名称静态检查通过。655 个 Python 文件记录哈希，用于核对测试源码及最终同步。
- 合成项目离屏打开/关闭通过，最长主线程停顿 68.1 ms；501 点/900 ns 的 451 ns 零时校正移动 250 点，保存后仍为 250 点。
- 独立差异复审在本轮修复范围内未发现剩余已证实 P1/P2；末轮定向兼容回归 63 通过、1 跳过。

## 验收边界

故障注入、子进程退出及合成数据用于验证软件一致性，不代替多 GB 实际工程、所有厂商数据、Windows 全部桌面交互或科学实测验收。七项跳过包含未提供的外部原始样本、跨盘专用场景和当前环境不适用的可选依赖缺失分支。未运行硬件、RTK 或远程链路测试。

本轮不更改版本号、不重建或安装 EXE；原有 0.11.2 安装包不包含此轮源码修复。
