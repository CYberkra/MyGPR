# 手动曲线增益验收记录

用户范围：只在 MyGPR 新增与上位机手动显示增益同规则的处理算法，归入增益分类。
未修改上位机、采集数据协议或文件导入。

方法号 `manual_gain`，显示名“手动曲线增益”。节点归一化位置以当前输入样点范围为准；
2～32 节点，−60～+60 dB，dB 域线性插值后按 `10**(db/20)` 乘入振幅。
默认 0 dB；输入不被修改，轴、道号和形状保留；分块沿列执行。
参数以节点快照写入处理链，成果及结果包包含计算后的矩阵与参数溯源。
