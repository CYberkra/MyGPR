# 2026-11-02 手动曲线增益实时预览

## 改动

- 曲线编辑器增加B-scan预览：增益前后切换、默认固定色阶、手动重新定标、全览与局部缩放。
- 当前项目/测线/所选原始或成果输入、数据修订、启用前置步骤均冻结在请求中。
  后台按64行读取完整输入，复用标准处理服务执行支持的前置步骤；不保存结果或草稿。
  前置计算完成后缓存输入，节点更新只做手动增益。
- 本次增益计算与正式处理共用domain层的归一化/分贝曲线规则，不另做灰度图增益。
- 节点更新100ms节流，最多一个计算在飞；连续拖动显示最近完成的同输入帧，
  保持“正在更新”提示与应用禁用，最后一帧匹配当前节点时才可应用。
  不同输入代号的旧结果始终丢弃；关窗取消令牌与定时器，不把后台结果交到已关闭窗口。
- 主参数区、步骤编辑弹窗均接线。改变项目、输入、前置步骤、原始修订或当前测线元数据时使旧预览失效。
- 原始矩阵、已保存成果和其他视图不改变；应用只提交参数，正式运行后才保存处理成果。

## 数据与资源边界

完整输入最多800万单元，保留全部行列与真实存储轴，不降采样。
可能扩展网格的前置时深转换、运动重采样与偏移先明确拒绝；需先执行并选其成果，
不在发生巨大分配后才用输出大小校验兜底。回归用例将该策略与注册表轴变换合同对应。

无效值预览使用完整输入均值填充，默认逐步保存路径一致。
既有可选文件分块路径对 NaN/Inf 可能逐块填充，属于原有执行差异；未在本轮改写其规则。
界面提示先修复无效值再作精确对比，文档不对这类输入声称跨路径逐值一致。
