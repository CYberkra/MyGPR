处理链路

四原子链先更新姿态/APC 足迹，再执行等距道距重采样，最后做高度时移和振幅归一，避免后续姿态更新破坏 speed compensation 的 trace axis。

RouteSteps说明
Atomictrajectory_smoothing -> motion_compensation_attitude -> motion_compensation_speed -> motion_compensation_height用于 ablation、教学展示和分项验证。
Unifiedmotion_compensation_v2推荐主线入口，统一输出 warnings、quality_flags 和 trace metadata。
