# 工作台动效验收记录

依据[工作台视觉与动效合同](../superpowers/specs/2026-11-25-workbench-motion-design.md)。Windows 原生对照从 `app_qt.py` 进入，基线为 `04dd492`，实施侧为独立验收工作树。使用同一台机器、同一套依赖及 1450 × 839 逻辑像素窗口。测试项目导入营山 L09 实测测线并运行去直流（窗口 41）与均值背景去除，打开原始输入和两项保存结果。数据矩阵为 501 × 2378、float32。源文件共 68,794,423 字节，前后 SHA-256 一致。

第一次 Qt Paint 是事件循环中的局部绘制时点。以上时长来自一对对照采样。合成器帧率、性能分布和多 GB 测线仍需独立测量。

同一实窗在当前物理 150% 环境运行通过。100% 和 200% 通过仅作用于验收进程的 Qt 缩放设置覆盖，200% 时窗口为 1177 × 629 逻辑像素。浅深主题、标签拖放、快速折叠、全屏和菜单均走原生 Windows 窗口。单物理屏条件下完成同屏全屏返回，跨屏复核待具备第二屏后执行。

浅／深主题的任务徽章对比度分别为排队与已取消 6.87／6.10、运行中 6.16／6.70、已完成 4.79／5.02、失败 5.91／6.47。色值按各主题实际前景和背景计算。

## Windows 补充验收

在同一硬件、实测数据和 150% 缩放下，窗口从真实入口启动并以 0 退出。结果见本机 `native-controls-150-final/report.json`。

- 键盘连续选择三个来源。受控交付 B 的实际预览数据时，下划线保留已运行的 45 ms。切到 C 后再次交付 B，C 仍显示自己的矩阵，旁组视口保持一致。向两个已有组发送 Qt 拖放事件，落区提示随目标组转移，Esc 清场，松手时标签正确移到目标组。
- 从子菜单按 Esc 回到父菜单，再按 Esc 回到入口按钮。修复前第一次 Esc 会同时关闭父菜单。减少动态效果下两层菜单直接显示，取消未执行动作。
- 营山 L09 原生点击当次写入解释表的 0 基坐标为 (998, 170)。放大后复核图内相邻像元和左、上边界外半个像元。后两处此前会误记首道或首样点，修复后十字线隐藏、点击不会追加点。
- 向隔离进程的真实窗口发送 `WM_SETTINGCHANGE`，在该进程内模拟系统偏好读取结果由开启变为关闭。进度条和工具栏完成当前过渡，下一次进度直接落位。宿主设置仍为开启。
- 全屏期间在同一物理屏中平移主窗 24 逻辑像素。Esc 回到移动后的原分组和布局位置，轴范围、色阶和对比组视口保持一致。
- 向任务协调器交付受控事件，核对未知总量、失败后启动新作业、迟到的旧进度和 AutoTune 失败提示去重。此前的实测作业继续覆盖真实后台取消。

独立工作树通过锁定版本 Ruff、Python 编译、架构、复杂度和技术债预算检查。GitHub Actions 待验收分支取得写入权限后运行。原生探针、JSON 与截图保存在本机 `output/motion-acceptance-20261125/`，其中 `compare-baseline-150` 与 `compare-ci-150` 记录本表的同环境对照。
