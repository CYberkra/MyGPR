# MyGPR 测试数据分层

## Tiny

位置：`tests/fixtures/`。规模控制在秒级，供单元测试、受影响测试和固定冒烟使用。不得依赖外部网络或设备。

## Standard

位置：`sample_data/` 中经过版本控制的标准样例。包含完整雷达矩阵、轨迹或处理元数据，用于跨模块集成、GUI 冒烟和报告闭环。

## Stress

不直接打入普通源码包。由发布环境或受控数据仓提供多 GB 数据、坏道、轨迹跳点、错误 CRS、磁盘不足和设备断连场景。只在夜间专项、发布候选和现场验收运行。

新增测试必须选择最低足够的数据层级。能由 Tiny 验证的逻辑不得使用 Standard；Standard 可以验证的功能不得默认依赖 Stress。
