#!/usr/bin/env markdown
# Curated Evidence Artifacts

This folder is for small, selected evidence files that are referenced by durable
documents in `docs/`.

Do not copy whole generated report folders here. Full HTML reports, replay ZIPs,
bulk B-scan PNGs, CSV exports, build outputs, and one-off screenshots should stay
under `output/` or outside the repository.

Add an artifact here only when all of these are true:

- A committed Markdown document references it.
- The file is small enough to keep Git history practical.
- The artifact is reusable evidence, not a temporary run product.
- The conclusion has also been summarized in text.
