# v0.8.83 项目预览真实化与 1080P 适配

本轮目标：在不改变算法入口和项目数据协议的前提下，解决 15.6 英寸 1080P 笔记本全屏显示不全的问题，并让首页/项目管理页预览卡更多跟随当前真实测线状态。

## 主要修改

- 默认窗口从 1920×1080 改为 1600×900，避免 Windows 125% 缩放下打开窗口超出可用工作区。
- 保留截图脚本 1920×1080 输出能力。
- 顶部栏高度从 126 压缩到 94，导航按钮、侧栏、卡片、表格和图像预览整体压缩。
- 首页 QScrollArea 禁用横向滚动，并使用紧凑内容尺寸。
- 项目管理页快速预览跟随 `selected_line` 和当前 active/processed dataset。
- 首页右侧 B-scan 预览跟随当前测线。

## 验收

- 1536×864 逻辑视口下，首页纵向滚动条最大值为 0。
- 六个主页面均可在 1536×864 截图中看到核心区域。
- 1920×1080 交付截图继续输出。
