# v0.8.84 1080P 实机适配修复

本轮针对用户在 15.6 英寸 1080P Windows 全屏下反馈的项目总览、项目管理、目标定位页面仍显示不全问题进行修复。

## 修复重点

- 顶部栏从 94px 压缩到 78px。
- 工作区边距、导航宽度、侧栏宽度继续压缩。
- 指标卡、表格行高、卡片标题高度、绘图卡高度压缩。
- 目标定位页 B-scan 和右侧标注面板压缩，目标表格限制最大高度，防止底部被挤出。
- 新增 1920×1020 截图验收，用于模拟带 Windows 标题栏/任务栏后的真实可用高度。

## 边界

本轮不新增业务功能，不改变算法入口，不改变项目数据协议。
