# MyGPR v0.8.74 术语与界面文案约束

## 必须避免的用户可见文案

- “单算法处理”
- “重采样类”
- 容易让用户误以为默认降低采样率或默认改变道间距的表述

## 当前推荐文案

- 右侧参数区标题：`处理设置`
- 算法分组：`算法分类`
- 算法选择：`选择算法`
- 参数区：`参数设置`
- 参数推荐按钮：`推荐当前参数`

## time_to_depth 表述

`time_to_depth` 应表达为：

- 时间-深度转换
- 显示与对比 / 坐标轴转换能力
- 结果需要记录轴变化和输出尺寸

不应表达为：

- 降采样
- 默认重采样
- 普通滤波

## 显示与对比能力放置

现阶段不新增顶部主导航页。相关能力先作为测线处理页或成果页中的子面板接入，成熟后再评估是否独立成页。
