# V0.8.11 Processing Lineage Compare Display Policy

处理链路对比是 display-only 诊断视图。由于不同处理步骤可能具有完全不同的幅值尺度，例如背景抑制与 AGC，直接共享绝对色标会导致低能量步骤在滑动对比中显示为近似灰块。

V0.8.11 对处理链路的滑动对比和网格对比采用每步骤独立稳健对称归一化：

- 对每个步骤取有限值。
- 以高百分位绝对幅值作为尺度。
- 将该步骤数据裁剪到 `[-1, 1]`。
- 所有面板使用统一 `[-1, 1]` 显示范围。

该策略只影响显示，不修改正式数据、不参与指标计算、不改变 Evidence 的正式处理链路。差值图仍基于未做该归一化的实际显示数组计算。

主图选道标记在 V0.8.11 退役。V0.8.12 进一步退役 hover 十字准线；主 B-scan 仅保留底部坐标读数作为默认检查交互，避免持久竖线或临时十字线干扰图像判读。
