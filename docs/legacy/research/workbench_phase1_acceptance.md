## 已知非阻断项

- `qfluentwidgets` 仍产生 SciPy 旧命名空间弃用警告。
- PyWavelets 在一个测试夹具中产生边界效应提示。
- 将全部 GUI 测试放入单个长期 Python 进程可能触发 Windows Qt / Matplotlib
  资源退出，因此最终全量门禁采用隔离批次执行。
