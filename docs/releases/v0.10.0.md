# MyGPR v0.10.0 — 采集 HDF5 与处理工作台

发布日期：2026-10-15。上一源码版本为 0.9.38；这是汇总后续功能更新的 0.x 功能版本。

## 本次更新

- **采集 HDF5 导入**：支持根 `/traces` 和内嵌 `/trace_meta`，将道×采样转换为
  采样×道，保留分量、缺测传感器、时间轴与未知距离。项目导入、预检和 CLI 共用该能力。
- **处理数据语义**：修复裁剪、保存、重开、增益与再次裁剪的采样间隔和累计时间偏移；
  没有测线长度时保留未知距离，迁移成像要求真实测距参数。
- **处理工作台**：汇总八页顶部导航、多成果 B-scan、A-scan 跟随、灰度/波形显示、
  高程轴及处理链编辑的更新。
- **稳定性与文档**：修复菜单原生崩溃、文件锁和异步任务边界、测试生命周期问题；
  同步依赖、README、AGENTS、用户手册及 SPEC 索引。
- **版本管理**：源码 VERSION、Python 包元数据、当前入口文档和变更记录一致；
  关于页与报告在源码和 wheel 安装下均读取实际版本。

## 下载和安装

本次 GitHub Release 提供：

- `MyGPR_V0.10.0_source.zip`：指定发布提交的源码，不包含本机未提交文件。
- `mygpr-0.10.0-py3-none-any.whl`：Python 包，默认安装无 Qt 后端；GUI 通过 `gui` extra 安装。
- `SHA256SUMS.txt`：发布资产的 SHA256。
- `release-manifest.json`：发布提交、版本、依赖基线、CI 和资产校验信息。

Python 支持 **3.12–3.13**。在新建虚拟环境中安装下载的 wheel：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install ".\mygpr-0.10.0-py3-none-any.whl[gui]"
mygpr
```

仅无头使用时去掉 `[gui]`，通过 `mygpr-batch` 运行 CLI。源码安装见
[README](../../README.md)。wheel 自身为纯 Python 包，依赖中仍包含平台原生库。
本次没有 exe 安装器；源码 ZIP 和 wheel 不能当成免安装桌面程序。
