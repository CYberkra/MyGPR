# MyGPR v0.11.0 — 项目与处理工作台

发布日期：2026-10-16；上一版本 v0.10.0。本版本汇总本轮维护、工作台改版与视觉精修。

## 使用范围

面向已完成测线文件的导入、预检、算法处理、成果比较、解释及项目交付工作流。
原有处理算法、后端 API 和依赖基线保持，平台对接范围见
[CDUT 平台对接说明](../developer/CDUT_PLATFORM_INTEGRATION.md)。
这次 Release 不表示父仓库采集端、实时接收端或统一安装器同步升级。

## 主要更新

- 项目入口统一：首页启动内容并入项目页，台账、详情、资源树和空态重新设计。
- B-scan 使用普通标签：原始输入与成果共同管理，支持排序、关闭恢复、跨组移动和
  画布边缘停靠拆分。当前激活的数据标签就是下一次处理输入。
- 顶部待执行算法链：点击调参并应用、拖动排序、启停、复制、替换和删除；每个输入
  保留独立草稿，已完成来源按需展开并可返回真实保存结果。
- 保存各步真实成果并记录 v2 直接输入依赖；从旧成果续算形成分叉。删除按依赖闭包
  确认，保留兄弟分支并保护运行中的输入。
- 完善对象菜单、键盘操作、运行草稿锁定和异步结果归属；修复旧菜单/弹层错写、
  预览串源、菜单确认取消崩溃、恢复项目和导入后选线等缺陷。
- 统一明暗主题、项目树、台账、标签与参数弹层，收紧顶部区域并检查窄窗口可达性。

## 下载与安装

Release 附件包括：

- `MyGPR-0.11.0-Windows-x64-Setup.exe`：内置 Python 和 Qt，按当前用户安装。
- `MyGPR_V0.11.0_source.zip`、`mygpr-0.11.0-py3-none-any.whl`：指定发布提交的源码与包。
- `SHA256SUMS.txt`、`release-manifest.json`：源码/wheel 校验、提交和 CI 证据。
- `WINDOWS-SHA256SUMS.txt`、`windows-build-manifest.json`：安装器校验及构建/安装验证。

Windows 安装器目标为 Windows 10 1809+ / Windows 11 x64；本轮验证主机为 Windows 11。
安装器未代码签名。构建和安装验证入口见 [Windows 构建说明](windows-build.md)。
Python 源码/wheel 支持 3.12–3.13，GUI 安装使用 `mygpr-0.11.0-py3-none-any.whl[gui]`。

## 升级与证据边界

升级前备份正在使用的项目。旧成果缺少可靠直接输入时显示“来源待核对”，不会根据
名字或时间猜测依赖；仅保存最终矩阵的历史运行不会伪造不存在的内部数据成果。
关闭标签仅影响视图，删除成果则检查实际依赖并确认影响范围。

本轮源码工作台已完成合成数据上的导入、分步处理、成果分支与原生 Windows 操作验证。
最终发布 CI、冻结包和安装/重装/卸载结果以附件清单为准。详见
[工作台合同](../superpowers/specs/2026-10-16-workbench-redesign.md)及
[视觉与操作验收](../artifacts/ui_visual_polish_20261016.md)。
这些证据不等于实测 UAV-SFCW 科学效果、多 GB 长跑、硬件闭环或物理分辨率验收。
已知 pytest 关停阶段 Qt 诊断与实际桌面退出结果分开记录；解释页底部坐标仍有
现存贴边布局边界。未单独验证 Windows 10、ARM64 或全树分页/虚拟化。
