# MyGPR v0.11.4 · 航空探地雷达处理工作台

MyGPR 是 CDUT-UavGPR 平台的独立处理端，面向滑坡等航空探地雷达（AGPR）测区，提供数据导入、质控、B-scan 处理、解释、空间成果与报告。

## 主要更新

- 项目启动区支持搜索和固定最近项目，处理成果显示可追溯的算法与参数。
- 项目、测线、处理成果及空间成果支持永久删除，确认窗口列出实际文件及依赖。最初导入的原始数据和传感器源文件保留，即使它们位于项目目录内。
- 改进全分辨率 B-scan、物理坐标、A-scan 和跨标签对照，已保存成果沿用自身的坐标与谱系。
- Windows 安装版提供签名更新。设置页的“关于”集中提供更新、离线下载与使用手册。
- 新图标以无人机和旋转滑坡剖面表现航空探测场景，采用石墨灰底与蜜杏色标志。

完整维护记录见 [CHANGELOG](../../CHANGELOG.md)。

## 安装与升级

从 [GitHub 正式发行页](https://github.com/CYberkra/MyGPR/releases/latest) 下载 Windows x64 安装器。目标系统为 Windows 10 1809 及以上或 Windows 11 x64，安装包内置 Python 与 Qt。安装器文件名为 `MyGPR-0.11.4-Windows-x64-Setup.exe`，校验值见 `WINDOWS-SHA256SUMS.txt`。

v0.11.0 等早期版本首次升级时，关闭 MyGPR，再手动运行新版安装器。v0.11.4 安装版可从 **设置 → 关于 → 检查更新** 获取后续版本。安装前会检查运行中的任务、未保存的标注和设置保存结果。

应用内更新以 Ed25519 校验安装包。Windows Authenticode 签名状态与更新包验签分别记录在发行材料中。源码和 wheel 支持 Python 3.12–3.13。使用发行附件中的 wheel 安装 GUI：`python -m pip install "./mygpr-0.11.4-py3-none-any.whl[gui]"`。
