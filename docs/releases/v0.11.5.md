# MyGPR v0.11.5 · 航空探地雷达处理工作台

MyGPR 是 CDUT-UavGPR 平台的独立处理端，面向滑坡等航空探地雷达（AGPR）测区，提供数据导入、质控、B-scan 处理、解释、空间成果与报告。

## 主要更新

- 采集标记由图像内贴顶散点改为 B-Scan 绘图区下沿的倒三角浮层：几何严格跟随 ViewBox，不额外占用布局高度；浅色与深色主题各用一档配色，保证灰阶图上的对比度。
- 标记可悬停查看源文件道号与标签；点击选中与点拾取模式解耦，未开启解释会话的预览页也能选中，再点一次取消，点空白仍照常拾取。
- 选中标记会广播信号、把该道平移进视野（只平移不改缩放），A-scan 波形跟随开启时切到该道。采集标记源记录始终只读。

完整维护记录见 [CHANGELOG](../../CHANGELOG.md)。

## 安装与升级

从 [GitHub 正式发行页](https://github.com/CYberkra/MyGPR/releases/latest) 下载 Windows x64 安装器。目标系统为 Windows 10 1809 及以上或 Windows 11 x64，安装包内置 Python 与 Qt。安装器文件名为 `MyGPR-0.11.5-Windows-x64-Setup.exe`，校验值见发行附件 `WINDOWS-SHA256SUMS.txt`。

v0.11.4 安装版可从 **设置 → 关于 → 检查更新** 获取本次版本；更早版本首次升级时，关闭 MyGPR 后手动运行新版安装器。安装前会检查运行中的任务、未保存的标注和设置保存结果。

应用内更新以 Ed25519 校验安装包。Windows Authenticode 签名状态与更新包验签分别记录在发行材料中。源码和 wheel 支持 Python 3.12–3.13。使用发行附件中的 wheel 安装 GUI：`python -m pip install "./mygpr-0.11.5-py3-none-any.whl[gui]"`。
