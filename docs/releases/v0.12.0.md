# MyGPR v0.12.0 · 事件区间与逐线报告

## 主要更新

- 在 B-scan 上查看点标记和事件区间。可以记录停车、干扰、目标范围及其他现场情况，也可单独保存期间没有采集道的时间事件。
- 按区间保留或剔除雷达道。提交前可核对选中道数、输出道数及断点，处理成果保存所用区间及其版本。
- 在处理侧栏搜索算法、编辑参数并连续添加步骤。处理记录可以按需展开，任务进度在底部查看。
- 按测线生成工程报告。路线和采集参数与剖面放在一起，正文可选用指定处理成果，并附处理记录、分析说明和交付校验。

已有采集文件与标记格式继续可读。新增标记和区间保存在项目内。打开正式项目进行升级前，建议先保存项目备份。

## 安装与升级

Windows 10 1809 及以上和 Windows 11 x64 可使用 `MyGPR-0.12.0-Windows-x64-Setup.exe`，安装包内置 Python 和 Qt。在 v0.11.5 安装版中，可通过 **设置 → 关于 → 检查更新** 升级。也可从发行页手动下载安装器，并用 `WINDOWS-SHA256SUMS.txt` 校验。

源码和 wheel 支持 Python 3.12–3.13。可用 `python -m pip install "./mygpr-0.12.0-py3-none-any.whl[gui]"` 安装图形界面。父平台通过 Git 子模块锁定 MyGPR 源码版本。独立 Windows 安装包和父平台安装包各有自己的发布记录。
