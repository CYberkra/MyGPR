# Processing Lineage Compare Toggle — V0.8.9

V0.8.9 将处理链路对比收口为单按钮 toggle 模式。

## User interaction

1. 点击处理链路中的一个历史步骤。
2. 点击 **与当前对比**。
3. 主图进入滑动对比：左侧为所选历史步骤，右侧为当前正式结果。
4. 再次点击 **与当前对比**，按钮取消选中，主图退出对比并回到单图当前结果。

## Design boundary

- 对比对象固定为：选中历史步骤 ↔ 当前正式结果。
- 当前正式结果不能与自身对比。
- 已被内存策略裁剪的步骤不能进入图像对比。
- 退出对比不修改正式处理结果。
