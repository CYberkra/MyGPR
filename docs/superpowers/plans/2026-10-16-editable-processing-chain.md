# 可编辑算法链实施补充

用户已批准直接实施：上方完整待执行算法链可点击调参、拖动排序及执行步骤操作；
B-scan 标签负责保存结果和处理输入，两者联动。此补充不恢复结果墙，也不改变算法。

## 落点与边界

- `ChainStrip` 复用并增强：关键参数摘要、重复点击编辑、稳定拖动来源/插入提示、
  键盘替代、溢出菜单与失效门卫。组件仅展示模型快照，不执行算法或维护第二套草稿。
- `ProcessingPage`：链放在工作区上方；左侧不再展示重复步骤列表。现有 PipelineList
  保留为内部步骤模型，执行顺序/参数/启停仍只有这一事实来源。
- `ProcessingSteps`：点击节点打开其下方参数弹层，应用后刷新摘要；编辑及结构命令
  捕获输入草稿和步骤身份，切线/输入/结构变化后旧窗口失效。Esc/关闭不应用。
- 已完成来源用只读导航显示；点击打开对应真实结果标签。修改已完成算法仍走
  “另建分支”，不会改写旧成果或把上游步骤重新装入待执行链。
- 任务冻结、独立草稿、取消保留、精确输出 ID、只保存真实成果的规则保持现行合同。
