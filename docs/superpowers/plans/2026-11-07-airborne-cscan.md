# 航空 GPR 振幅切片与三维测线 Implementation Plan

**Goal:** 在空间信息页提供可追溯的振幅时间切片、测线 B-scan 联动及三维剖面视图。

**Architecture:** 后端按测线分块计算逐道窗口属性，在共同米制坐标中按测线聚合；UI 通过后台命令请求结果，并复用现有空间地形与 B-scan 组件。时间轴、分量、测线映射或坐标不可证实时拒绝物理解释，不插补未覆盖网格。

**Tech Stack:** Python、NumPy、SciPy、PyQt6、pyqtgraph、现有项目数据与任务接口。

## 范围和约束

- 首先支持采集时间窗、RMS / 平均 / 最大振幅、原始及可验证时间轴与逐道位置映射的处理成果。`real` 可选包络；`mag` 直接使用；语义未核实的 `fdata` 不当作时域振幅。
- 每条测线的有效样点、时间轴约定和输入成果独立记录。均值先按测线内网格汇总，再对测线取均值，避免高采样密度控制结果。空格保持 NaN。
- 三维图优先显示地形与沿实际轨迹的 B-scan 幕帘；时间轴不能直接映射成真实地下高程。已确认地表基准、速度和坐标时才能提供深度视图。稀疏测线默认不生成连续振幅体。
- 所有计算支持大文件分块、取消和过期结果防护；保存成果记录源和参数，删除不触及用户源文件。
- 自动化测试及冒烟由 GitHub Actions 执行；真实航空数据、桌面交互和 OpenGL 单独验收。

## 工作项

- [ ] 数据契约：核对原始及处理成果的时间轴、分量、逐道定位与生命周期；增加可验证的输入和错误路径。
- [ ] 计算内核：完整道分块计算包络与窗口属性；统一 CRS、按测线加权网格；覆盖缺失、越界和不完整窗口。
- [ ] 平面界面：选择测线和各自成果、设置时间窗/属性/网格、切片浏览、覆盖显示和 B-scan 回查。
- [ ] 三维界面：复用地形和轨迹视图，显示实际剖面幕帘，与平面切片和选中道联动；标清时间域与高程域。
- [ ] 成果：保存可复现参数、逐线源标识、坐标与有效覆盖；导出与删除走现有空间成果语义。
- [ ] 验收：合成数据验证精确时间窗、分量和网格统计；GUI 异常与过期任务；CI 及真实航空数据的交互、地形和显示验证。

## 验收边界

不以合成截图代替真实航空验证；不把插值体、单一速度近似或三维显示当作滑坡面的证明。既有 OpenGL 兼容问题在目标桌面完成验证前不得视为已解决。
