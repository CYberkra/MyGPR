# 标记与事件区间实施记录

## 已确认合同

采集原记录只读；项目内修订、新增点标记和事件区间。独立标记条、共享列表及详情。
区间允许重叠、开放端、时间事件；复核后显式保留或剔除，生成新成果。

处理、解释、空间与交付使用同一身份和固定快照。源文件不回写。
