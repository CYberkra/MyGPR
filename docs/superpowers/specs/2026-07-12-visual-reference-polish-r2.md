# MyGPR 五页视觉参考版第二轮精修

## 范围

本轮不改变业务流程和项目数据模型，只收口五页主壳层与工作台的视觉语言、信息层级和响应式行为。

## 已完成

- 蓝色品牌体系与高 DPI 脉冲标识。
- 跨平台中文无衬线字体回退。
- 顶部项目切换、工程状态与全局动作层级。
- 工程上下文带、工作站容器、状态徽标与目标列表列宽。
- 测线处理步骤链和控制舱。
- 报告封面与导出控制层级。
- 1280×720 至 2560×1440，以及 125%/150% 缩放自动验收。

## 冻结规则

1. 不使用绝对坐标拼接页面。
2. 主图必须保持页面视觉主导权。
3. 低频动作进入“更多”或次级区域。
4. 1280×720 可使用页面级滚动，但一级动作与主图必须保持可见。
5. Windows 11 真机字体与高 DPI 结果是最终像素冻结依据。
