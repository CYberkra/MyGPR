# 工作台与成果分支现行合同

日期：2026-10-16。适用：本轮源码工作区；不表示已发布安装包更新。
实施与验收见 [工作台改版记录](../../artifacts/workbench_redesign_20261016.md)。
顶部链交互补充见 [可编辑算法链验收](../../artifacts/editable_processing_chain_20261016.md)。
视觉精修与原生证据见 [工作台视觉精修记录](../../artifacts/ui_visual_polish_20261016.md)。
本合同替代旧处理页自动四窗、原始输入不可关闭、结果库/画廊和运行自动展开方案。

## 项目入口

顶部导航为项目、处理、解释、空间信息、成果、任务、设置七页。首页内容并入
项目工作区；`homeInterface` 仅保留旧调用兼容。无项目时显示新建、打开和最近项目；
空项目引导导入；有测线时显示台账与所选测线详情。项目切换放在窗口左上角菜单。
导入、预检、同步等仍使用现有控制器和任务链，表单通过相应工具入口打开。
多选时只提供适用于所选集合的动作。后台命令和任务约束继续保护项目切换/关闭。

## B-scan 工作区

- 原始输入与保存成果使用同一种标签；原始输入默认不固定，可关闭。
- 默认单组。增加标签不自动分屏；拖动标签排序、跨组移动或拖到画布边缘拆分。
  分组间距由分隔条调整；菜单与快捷键提供等价操作。
- 固定标签由用户主动设置；普通关闭遵循固定状态。删除资源时强制移除对应视图。
  关闭全部保持空工作区，迟到预览不能补开标签。
- 标签过多时滚动并从已打开列表定位。关闭和恢复仅影响视图；不删除保存成果。
- 每组复用一个 BScanView。源目录更新只登记元数据；可见视图按需异步读取预览。
  bundle 按引用交付，显示色阶、增益、色图和视口不改变雷达数据或生成处理步骤。
- 成果标签由持久化 lineage 生成短处理动作，1–3 步直接显示，长链按处理目的归类；
  完整算法、参数、累计步数与警告集中在标签悬停和右键详情，不常驻占用画布空间。
  这些文案不声称未经测量的科学质量提升。
- 项目资源、处理工具使用工作区标题栏的小图标开关。布局不另占完整控制行。

## 输入、草稿与任务

当前主动激活的有效数据标签就是下一次处理输入。选择标签不执行算法，画布上方的
“待执行”算法链只包含准备追加的新步骤；不能把已完成的上游处理自动填回并再次执行。
点击算法节点打开紧邻节点的参数弹层，“应用”写入草稿，Esc/关闭丢弃未应用参数。
节点可拖动排序，并提供上下移动、启停、复制、替换和删除；左侧保留参数与 AutoTune
工具，不重复显示步骤列表。标签拖动仅调整结果视图，算法链拖动才调整执行顺序。
已完成来源另以只读路径导航，点击打开对应保存结果；不重放算法，也不改写旧成果。
切换输入或测线关闭旧弹层；草稿发生编辑后，旧菜单、拖动和算法替换目标失效，防止
相同摘要或相同算法的不同步骤之间发生错写。追加选择器可连续添加算法。
草稿按项目、测线、稳定数据 ID 和已有数据哈希/修订隔离。关闭标签和切换页面保留草稿；
数据身份变更不能静默复用旧缓存或草稿。失效输入禁用提交并显示原因。

提交时冻结输入、步骤配置和中间成果保存选项。默认保存并自动打开每个实际保存的步骤结果，
最终成果保持活动输入；大测线可关闭中间成果以优先分块。运行前资源预估展示执行模式、峰值内存与临时磁盘。
批量应用只把当前处理链用于所选测线的原始输入，不跨测线共享 artifact ID，失败逐线隔离。
同一工作台有任务运行时不能再次提交；该任务输入草稿锁定，
其他结果仍能查看和配置。成功只清除提交源的草稿；失败/取消保留。
完成回包按实际 job ID 与最终 artifact ID 识别。从提交到完成没有改变浏览上下文时，
自动激活新最终成果；用户切标签、切页或关闭输入后，保留浏览状态并提供查看结果入口。
部分已经保存的成果仍是实际资源，不能因后续失败而假称不存在。

## 真实来源与分叉

新成果 metadata 使用 `lineage_version=2`：

| 字段 | 语义 |
| --- | --- |
| `run_group_id`、`run_step_index` | 运行身份和原执行步骤序号，包含最终成果 |
| `run_input_artifact_id`、`run_input_sha256` | 整次运行的冻结输入 |
| `step_input_artifact_id`、`step_input_sha256` | 该保存输出实际可读取的直接输入 |
| `pipeline`、`lineage` | 提交配置和各步方法、参数、实现信息 |
| 旧 `parent_artifact_id` | 保持整次运行输入语义，兼容旧存储与消费者 |

项目树按直接输入画父子关系：A→B→C 后，从 A 再处理得到 D，B 与 D 为兄弟。
相同配置重跑生成独立成果，不覆盖旧数据。只保存最终矩阵的运行不会伪造不可读取的
内部步骤成果。旧数据缺少可靠直接边时归入“来源待核对”，不能靠名字/日期猜测。
树中任务占位不可选择、没有成果 ID；运行输入用文字角标标明。

“修改此步参数并另建分支”回到该步真实已保存输入，只载入这一方法。
最终矩阵包含多步而缺少紧前步骤保存输入时，该动作禁用。
历史“按原输入重新配置本次运行”使用完整运行配置，仍需用户主动运行。
替换非空草稿须明确确认；取消不改变输入/草稿，替换前备份并可恢复。

删除按实际依赖闭包查询和确认，不按运行号或时间猜测。删除一条分支保留兄弟；
运行引用的输入及祖先受保护。中间成果清理保留 v2 直接输入、旧运行显式输入和分支头，
不通过静默重挂父级掩盖缺失来源。关闭标签与删除成果是独立命令。

## 菜单与视觉

右键只命中并展示对象菜单，不激活另一处理输入。菜单捕获稳定身份；项目/测线/对象
切换后失效，执行删除时再次检查任务依赖。项目树、处理来源/历史、解释点、空间测线、
交付成果、任务表分别提供与真实能力对应的对象动作；文本框保留原生编辑菜单。
没有后端能力的重试、删除或导出动作明确禁用并说明原因，不弹出假成功。
Shift+F10/Menu 与可见更多按钮提供键盘及点击入口。显示详情可复制、可滚动。
预览错误保留在对应源，支持显式重试，迟到回包不改变活动输入。

采用中性面板、克制的蓝色强调、统一图标和间距，支持明暗主题。
活动输入与任务状态同时使用文字，避免只靠颜色辨认。
视觉精修将资源/工具开关、测线、活动输入、布局、来源与执行合并到一行工具栏。
已完成来源默认收起，通过工具栏小按钮展开；此显示操作不改变输入或草稿。
活动输入长标题省略显示并保留完整 tooltip。算法链不重复显示输入标题。
步骤节点与结果标签分别统一为 28px 与 32px；参数弹层采用一致的自绘标题与关闭钮，
关闭/Esc 不应用。附件默认折叠，用户展开状态在主题重建后恢复，包括空目录。
图表背景、轴文字与色条字体使用共同主题；色图、色阶、坐标范围及科学矩阵不因换肤改变。
本轮不新增依赖、算法或推荐科学参数。深链构建使用迭代遍历；尚未实现全树分页/虚拟化，
不把小数据 UI 验收当成多 GB 数据或科学效果验证。
