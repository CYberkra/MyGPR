# MyGPR 全软件美术重置提案：清爽精密

日期：2026-10-17。状态：**已按用户要求暂缓，保留草案；不是现行合同，不表示已经实施或验收。** 当前工作转为现有软件维护。

本轮只规划全软件视觉、布局与操作呈现。用户允许推翻现有美术，已选择“清爽精密：浅色为主、克制留白，兼顾工程信息密度”。本文件提出统一方向和实施顺序；批准前，[2026-10-16 工作台现行合同](2026-10-16-workbench-redesign.md)继续有效。美术规划不等于改算法、真实数据验证或框架迁移；不调整科学参数、数据格式、后端接口、线程模型和存储约束。

配套本地 [七页可点击概念示意](../../../output/art-direction-20261017/index.html)用于评审布局与视觉层级。它采用示意数据与模拟交互，不是软件截图，不连接真实项目，不代表产品能力或最终控件精度。页面上的 B-scan、地图、任务与导出状态均不能作为科学结果或产品验收证据。

## 1. 要解决的设计问题

MyGPR 是处理、成像解释与成果交付工作台。主视图应让用户先辨认当前项目、当前对象、当前数据输入和可执行动作，再查看参数、状态与来源。画布、测线台账、解释点和交付成果是页面主体；大标题、重复外框和装饰性留白不占据这些内容的空间。

本提案重新组织外壳和七页的视觉层级，不沿用“换配色即完成”的范围。目标是：导航稳定，画布足够大，数据状态可读，专业操作可发现，长期工作不疲劳。处理页最重要的判断保持清楚：我现在看哪个数据、下一次从哪个数据算、准备算哪些新步骤、保存成果来自哪里。

规划依据为仓库 [AGENTS.md](../../../AGENTS.md)、[CLAUDE.md](../../../CLAUDE.md)、[规格索引](README.md)、10 月 16 日现行合同，以及 `frontend-design-polish` 的工程工具设计与检查清单。现行源码能力最终仍需按页核验；文档和概念示意不补足未实现功能。

## 2. 三种外壳方案与选择

| 方案 | 布局与收益 | 成本与限制 | 判断 |
| --- | --- | --- | --- |
| A 顶部导航修整 | 保留七个顶部页签，缩小冗余间距，统一颜色和表单 | 改动较小；导航、项目上下文、处理工具仍争夺顶部水平空间，全软件层级改善有限 | 可作保守过渡，不能充分实现本轮重置 |
| B 左侧主导航 | 顶部项目上下文，左侧窄导航，页面按任务安排资源/画布/详情 | 七页和数据规则保留；路由呈现、布局持久化与快捷键需重新核验 | **推荐：兼顾画布、稳定定位与实施复杂度** |
| C 重型 IDE 停靠 | 大量工具窗口可自由停靠、浮动，多画布高度可定制 | 学习与恢复成本高；新用户难预测工具位置；高 DPI、小屏和布局持久化更复杂 | 暂不采用；先保留必要分隔条和收起能力 |

推荐 B，但不把每页强制做成三栏。资源树和详情检查器都是按任务出现的辅助区域，画布或主表优先获得空间。

## 3. 全局外壳与空间分配

所有尺寸均为 **Qt 逻辑像素**，不是物理像素。DPI 缩放后按逻辑布局判断可用空间。

| 区域 | 初始建议 | 职责与约束 |
| --- | --- | --- |
| 顶栏 | 高 48 | 品牌、项目切换、当前测线/对象上下文；窗口按钮遵循原生行为。项目名称有完整提示与复制入口，不重复放导航 |
| 主导航 | 宽 64 | 图标与中文短名：项目、处理、解释、空间、成果；任务和设置置底。保留七条路由与旧首页兼容，不新增首页 |
| 页面资源区 | 初始宽 224，可拖宽、可收起 | 处理项目树、空间图层等；不同页面按需要出现，不为对称预留空侧栏 |
| 主内容 | 分配剩余空间 | B-scan、地图、台账或成果列表，横向及纵向都优先；无装饰性外层卡片 |
| 右侧详情/参数 | 初始宽 288，可拖宽、可收起 | 对象详情、节点参数、生成配置等单一当前上下文；复杂长表单可扩宽，不压缩到不可读 |
| 全局底部状态 | 收起时约 24 | 当前任务摘要、连接/保存等已有状态、展开日志入口；任务页承担完整管理，不重复常驻任务表 |

主导航选中态使用浅蓝底、强调色文字与可辨认的选中标记，不能只改变图标颜色。页面内部实体名称可用 18px，例如“Line9”或“成果”，避免增加一条只重复当前导航名称的大标题横幅。

顶部上下文和页内操作按职责分开：全局只说明项目与当前位置；处理页紧邻画布的一行工具栏说明活动输入、布局、来源入口和运行。宽度不足时低频操作进入有文字的“更多”菜单，运行和活动输入保持可见；不靠无限缩小字体挤成一行。

### 3.1 窗口与 DPI 策略

| 可用逻辑尺寸 | 布局策略 |
| --- | --- |
| 1920 × 900 及以上 | 可同时展开资源与详情，主画布仍占主要区域；用户可主动隐藏任一侧栏 |
| 1440 × 900 | 支持日常两栏或按需三栏；右参数检查器开启时评估画布宽度，不自动开启资源区 |
| 1280 × 720 | 优先主视图与一个当前辅助栏；首次进入或空间不足先折低优先级辅助栏，保留显式恢复入口 |
| 高度 720 | 表单内部滚动，工具栏不随内容消失；底部完整日志默认收起，轴与色条不能被盖住 |
| 高度 900 | 增加画布和列表可见行，不同比例放大按钮与留白 |

资源区和详情区不强制同步开关；空间不足时优先折资源，再折非活动详情。用户正在编辑的参数不因自适应直接丢弃，必须先保存未应用编辑的局部状态，待用户应用或放弃；不得因布局变化写入算法草稿。展开宽度与可见状态按页面记忆，失效或超出窗口范围时恢复到可用布局，提供“恢复布局”。

桌面验收覆盖 1920/1440/1280 的逻辑宽度、720/900 的逻辑高度和 100%/125%/150%/200% DPI。实际物理屏幕无法提供某种逻辑尺寸时注明限制，不能把浏览器缩放当成 Qt 字体和多屏 DPI 验收。

## 4. 七页逐页设计

### 4.1 项目：台账为主，详情在右

无项目时保留新建、打开、最近项目；空项目用一条清楚的导入引导。已有项目时，主区为测线台账，顶部紧凑显示项目名称和必要统计，主操作为导入；预检、同步等通过现有工具入口打开。

台账行按现有可用字段呈现测线名、数据概况、状态与最近更新。状态文字与图标并用；不要把缺失字段当零值。所选测线的路径、采样/坐标概况、附件和下一步动作进入右详情，不再用上下两个大块挤占台账。大批量操作使用多选工具条，只显示适用动作和选择数量。

选中台账行只更新项目页详情；“进入处理”等显式动作执行原有跨页行为。项目切换仍受任务约束保护。附件默认折叠并记忆用户展开状态，空目录也可恢复状态。关闭视图与删除资源不能用一个含糊的“移除”按钮混淆。

### 4.2 处理：活动输入、待执行链、画布、参数各有位置

默认打开一个普通 B-scan 组，原始输入与保存成果使用同一种标签，原始输入可关闭且默认不固定。增加标签不自动分屏；由用户拖到画布边缘拆分，或用菜单/快捷键完成等价操作。组间分隔条可调，每组复用一个视图，过多标签滚动并提供“已打开”列表。

画布上方按顺序安排紧凑上下文工具栏、待执行链与结果标签。活动输入在工具栏和活动标签上都有明确文字/标记。链仅表示下一次运行追加的新步骤；历史来源以独立只读路径或右侧详情呈现，默认收起，不能把历史填回待执行链。改变色阶、增益、色图、视口与显示布局均属显示操作，不修改科学矩阵或生成步骤。

算法库保留分类/搜索和连续追加能力；用一次打开的工具抽屉或资源区中的专用面板呈现。节点参数放入右侧检查器，AutoTune 等已有工具放在对应参数上下文，不常驻重复步骤表。运行主按钮附近说明有效输入、步骤数量及禁用原因；运行时不锁死其他成果的查看。

节点从“算法名和所有参数塞在一块”改成稳定三层：步骤序号与算法名为主要信息，1–2 个重要参数摘要为次级信息，启用/禁用/编辑未应用等状态用文字或小标记补充。具体摘要按注册元数据定义，不能凭美术任意隐藏科学关键信息。完整参数在检查器可读、可复制。长名称省略保留完整提示；拖柄、更多与删除动作不因长名称被挤出。

节点排序只改变执行顺序，结果标签排序只改变浏览顺序。节点拖动用节点宽度的占位与插入线，标签拆分用画布边缘落区；两者的反馈、命中区域、帮助文案和键盘命令明确区分。

#### 参数检查器的编辑事务

这是对现行“紧邻节点弹层”的**新提案**，批准并实施前仍使用现行规则。检查器标题固定显示所编辑的稳定节点、算法与输入上下文；字段变化先留在局部编辑副本，“应用”才写入草稿，不立即执行。Esc、关闭检查器或关闭参数编辑放弃未应用变更，恢复最后已应用值。对无未应用变更的检查器，Esc 仅退出编辑。

切换算法节点、活动输入、测线或项目前检测未应用变更，提供“应用/放弃/继续编辑”；取消切换保持原对象。应用前重新核验项目、测线、稳定数据 ID、数据哈希/修订、节点 ID 与草稿版本。上下文已经失效则禁用应用并说明原因，不能将旧字段写到新输入、相同名称节点或相同算法的另一步。提交冻结后，运行源的参数只读；其他输入可按现行规则配置。

键盘焦点进入检查器后按字段顺序移动；应用后焦点回到所编辑节点；关闭/丢弃后回到触发入口。对可能已有局部编辑状态的面板收起，收起仅隐藏而不应用、不执行、不丢弃，标题/入口保留“未应用”提示；明确关闭编辑才丢弃。

#### 来源与任务反馈

资源树按实际直接输入分叉，A→B→C 后从 A 得 D 时，B 和 D 为兄弟。缺乏可靠直接边的旧成果放入“来源待核对”；不猜测、不伪造未保存的内部步骤。树中任务占位不可选择且不具备成果 ID。

右键只命中对象并打开菜单，不切换下一次处理输入；查看详情也不等于激活处理输入。菜单及未完成编辑都捕获稳定身份，在上下文改变后失效。修改历史参数另建分支、按原输入重配、替换非空草稿的确认/备份恢复、按依赖删除与祖先保护，全部沿用现行合同。

提交冻结输入和步骤；同一工作台任务运行时不可再次提交。成功仅清理提交源草稿，失败/取消保留。完成按真实 job ID/artifact ID 识别；用户已改变浏览上下文时不抢焦点，以可点击结果提示交付。已经保存的部分成果仍可见，并清楚标记本次运行的后续失败或取消。关闭全部后迟到预览不能补开标签，预览错误保留在对应源并提供显式重试。

### 4.3 解释：画布优先，小工具条与右侧点表

中心为当前 B-scan 与已有解释叠加。顶部小工具条按选择、拾取/编辑、撤销等真实能力组织，坐标、单位和当前工具状态可见；低频显示选项收进菜单。右侧点表显示当前解释对象的实际字段，支持定位、编辑、复制等已有动作，并保留原生文本编辑菜单。

点选画布与点表需要双向定位，但不得静默改变处理页活动输入。点表宽度按列可用性调整，长备注用详情展开，不把右栏扩成另一主页面。无解释时说明当前测线与第一步操作；无有效数据时显示依赖原因。插值、自动识别、新增模型等未核实能力不能作为美术重置默认承诺。

### 4.4 空间：地图/三维主视图，图层与按需对象详情

地图或已有三维视图占中心，左侧放图层列表与可见性，选中对象后按需打开右详情。图层可见性、对象选中和分析输入是不同状态；保持尺度、坐标参考、选中测线和缺失坐标警告可读。地图/三维切换使用明确模式标签，仅展示当前产品实际支持的入口。

轨迹、测线、解释成果和底图应按真实数据类型分组；无坐标、投影不一致或缺少输入时就地显示原因，不伪造地图落点。三维联动剖切、任意纹理、在线底图、新 GIS 编辑器等若未完成，进入候选能力清单，不能用可点击外观让人误认为已接通。

### 4.5 成果：成果列表与生成侧栏

主区显示已经生成的真实成果，按类型、所属测线、状态、时间和路径等可用字段检索。右侧“生成成果”侧栏分组填写已有模板、范围、参数和输出路径；生成按钮与校验结果在同一区域。模板、范围、输出选择避免用多层大卡片包裹。

选择已有成果时右栏切到详情/预览及真实的打开、定位、导出等动作。正在填写生成配置时，不因选择列表行静默丢弃表单；用户明确切换上下文。任务进度引用任务系统，实际文件存在与生成任务状态分开表达。导出失败、部分成功、路径不可写等在对应项显示可复制信息，不弹出假成功。

### 4.6 任务：一个主列表，一个详情区域

任务页保留一个可筛选主列表及所选任务详情，详情显示阶段、输入/输出引用、日志、进度和已支持的取消/清理操作。页面有运行中任务时可自动定位到相关行，但不在用户检查旧任务时持续抢选择。

全局底栏只显示摘要和进入任务/展开日志入口，任务页不再与另一个常驻完整任务列表形成双重浏览。现有任务事件、取消语义与依赖检查保留，视觉呈现合并不意味着合并后端身份。无后端支持的重试或删除明确禁用并给原因；错误日志可选择、滚动和复制。

### 4.7 设置：分组导航与紧凑表单

设置页采用页内分组导航与主表单，按现有设置归入外观/显示、处理偏好、路径与存储等实际组。没有对应设置则不创建虚构开关。主表单保留适当阅读宽度，宽屏空余空间用于帮助/当前值，不拉长输入框到全窗口。

布尔值用开关/复选框，互斥模式用分段/下拉，数值带单位和有效范围，路径用输入与浏览按钮。区分立即生效、需应用和需重启；显示默认值、改动状态与恢复默认作用域。科学参数不能以“美化”名义设置新的推荐默认值。

## 5. 组件与视觉系统

### 5.1 浅色语义颜色

| Token | 候选值 | 主要用途 |
| --- | --- | --- |
| canvas | `#F5F7FA` | 软件工作背景 |
| surface | `#FFFFFF` | 主画布外的内容面、列表与输入表面 |
| panel | `#EEF2F6` | 辅助侧栏、弱分区背景 |
| ink | `#1F2B3D` | 主正文、实体名称 |
| secondary | `#536276` | 面板文字、次级正文 |
| muted | `#637287` | 白色/画布上的辅助文字；深浅底分别核验 |
| line | `#DCE3EB` | 分隔线、非必要装饰边界 |
| controlBorder | `#8A98A9` | 候选细描边，不可独立承担必要控件边界 |
| controlBorderStrong | `#7C8A9B` | 必须可辨认的输入、按钮及交互边界建议修正值 |
| accent | `#245CC5` | 主动作、活动态、焦点 |
| soft | `#EAF1FF` | 选中/活动浅底 |
| success | `#19734C` | 成功状态文字与图标 |
| warning | `#996400` | 待核验、部分成功、警告 |
| error | `#B9353F` | 失败、无效输入、破坏性动作 |

蓝色只强调活动位置和主要动作，不给每个面板都加蓝头。成功、警告、失败保留文字与图标，色彩只辅助识别。科学色图、色阶、坐标与数据矩阵不随主题变化。阴影只用于菜单、浮层等覆盖关系；页面分区通过空间和必要分隔线表达。

以 sRGB 相对亮度计算，`ink/white` 约 14.27:1，`secondary/white` 6.22:1，`muted/white` 4.90:1，`muted/canvas` 4.56:1；但 `muted/panel` 约 4.35:1，不满足小字 4.5:1，因此 panel 上用 secondary。`controlBorder/white` 约 2.94:1、对 panel 2.61:1；建议强边界对两者约 3.52:1、3.13:1。浅分隔线约 1.29:1，只能装饰，不能作为唯一可操作性标记。主按钮白字对 accent 约 6.15:1。以上是纯色组合计算，最终仍需核验实际渲染、透明度与所有状态。

### 5.2 字体、节奏和密度

| 用途 | 初始建议 |
| --- | --- |
| 辅助标签、简短状态 | 11px；不得承载唯一关键警告 |
| 元数据 | 12px |
| 正文、控件、菜单 | 13px |
| 组标题、重要小标题 | 14px，适当字重 |
| 页面当前实体标题 | 18px；不做大字号欢迎横幅 |
| 字体 | `Segoe UI`、`Microsoft YaHei UI` 等系统字体，按实际中文回退验证 |
| 基础间距 | 4px 网格；常用 4/8/12/16/24 |
| 常用控件 | 32px 高，文本输入和按钮对齐 |
| 表格行 | 36px，密度偏好可在验证后精调 |
| 结果标签 / 算法链 | 初始高 34px / 34px；这是取代现行 32px / 28px 的候选值 |
| 圆角 | 控件 4px、分组 6px、浮层 8px，避免胶囊泛滥 |

字号与高度都允许基于中文实际渲染精调。链参数摘要以短摘要、完整检查器为主；不能为满足固定 34px 高度把核心文字缩成不可读小字。数值列可用等宽数字，科学式、单位、正负号和小数位按数据语义显示；不修改数值精度以迎合列宽。

### 5.3 核心组件合同

| 组件 | 统一规则 |
| --- | --- |
| 操作按钮 | 每个任务区一个明确主动作；次要按钮用中性表面；破坏性动作与普通关闭分开 |
| 图标按钮 | 一套风格与笔画；有 tooltip、可访问名称和键盘入口，触发目标不小于可用点击区域要求 |
| 导航 | 图标+中文短名；当前项有文字、形状和色彩共同标记；缩窄不隐藏全部含义 |
| 表格/树 | 选中、焦点、悬停、多选各自可辨；操作不依赖悬停；长名可定位并查看完整内容 |
| B-scan tabs | 普通/固定/活动/加载/失败可辨；关闭不删除；活动状态对应真实处理输入 |
| 算法节点 | 序号、算法名、摘要与状态分层；显式待执行身份；拖动提供合法目标提示 |
| 检查器 | 单一当前编辑对象；字段标签、单位、范围、错误就地显示；应用/放弃语义稳定 |
| 状态标签 | 文本优先，图标辅助；不把“部分成功”渲染成完整成功 |
| 菜单 | 按实际对象与能力列动作；稳定身份；禁用原因可发现；文本框保留原生菜单 |
| 提示/错误 | 短结论、原因、可执行下一步；关键错误常驻对应对象，可复制诊断详情 |
| 空态 | 描述缺少什么并提供一项合理下一步；区分无项目、无数据、无选择、无结果、失败与无权限/依赖 |
| 分隔条 | 有可辨拖动反馈和恢复入口；拖宽只改变布局，不改变显示数据或输入 |

暗色沿用相同语义 token 和组件状态，另行配对背景/文字/边界，不通过整体反色生成。暗色不改变坐标、色阶、算法参数与资源关系；不可用暗色截图代替浅色主方案验收。

## 6. 交互状态与可访问性

| 状态/情境 | 必须看到的反馈与行为 |
| --- | --- |
| 无项目/空项目 | 清楚的新建、打开、导入入口，失效后续操作给原因 |
| 预览加载 | 保持源身份和画布尺寸；加载提示不伪装成功；可见源按需加载 |
| 无有效输入 | 运行禁用，说明未选、丢失、哈希/修订变化或其他真实原因 |
| 草稿未应用 | 编辑对象可见，明确“未应用”；切源防错写，Esc 可丢弃 |
| 运行 | 阶段/进度按真实事件展示；运行源草稿锁定，其他成果可看 |
| 失败 | 对应对象保留错误和已有成果；恢复动作有能力才启用 |
| 部分成功 | 明确已保存哪些、后续哪步失败，保留实际资源，不用整条绿色成功 |
| 取消 | 表示取消请求和最终取消是不同阶段；草稿与实际已保存结果按合同处理 |
| 拖动 | 合法插入、拆分、跨组和非法目标分别反馈；Esc 撤销拖动 |
| 长名称/大量项 | 省略、完整提示、复制、滚动/已打开列表，不覆盖主要动作 |
| 焦点/禁用 | 焦点轮廓清晰；禁用原因可通过相邻说明或键盘访问入口获得 |
| 空目录/缺字段 | 保留结构与真实缺失原因，不编造默认结果 |

全部菜单动作有 Shift+F10/Menu 或可见更多按钮入口；拖动排序、跨组移动与拆分有菜单/快捷键等价操作。Tab 顺序遵循视觉区域，焦点跨面板可预测，关闭浮层后回到触发者；不覆盖文本框的原生编辑键。主导航、对象列表、算法链、画布工具和检查器应能仅键盘完成主要流程，具体快捷键表在实现前盘点已有绑定，避免冲突。

正文和小标签的实际颜色组合目标至少 4.5:1；大字至少 3:1；必要控件边界、选中/焦点指示至少 3:1，并在真实背景上计算。验证高对比模式和系统字体缩放；禁用样式虽可弱化，原因文字仍要可读。不能只依靠颜色区分活动输入、任务状态和警告。

## 9. 具体验收清单

以下是将来实现的验收要求，**不是本轮已经通过的检查结果**。

### 9.1 视觉与布局

- [ ] 七页使用同一 token、字体、按钮、菜单、表格和状态语言，资源/详情区没有无意义嵌套卡片。
- [ ] 1920/1440/1280 逻辑宽、720/900 逻辑高可工作；参数表单滚动，主要动作可达，图表轴和色条无裁切。
- [ ] Windows 100%/125%/150%/200% DPI、中文/英文/混合长名称和多屏缩放无重叠、文字截断或跳动。
- [ ] 两侧栏可独立收展、拖宽与恢复；不足空间不强开三栏，不丢未应用参数，不改变活动输入。
- [ ] 颜色组合逐项测量，文字/焦点/必要控件边界达标；浅色、暗色与高对比均保留同等信息。
- [ ] 空态、加载、禁用、失败、部分成功、取消、长名称、拖动目标都可见且可理解。

### 9.2 关键行为保真

- [ ] 原始与成果可普通关闭；新增 tab 不自动拆分；标签排序与算法节点排序互不影响。
- [ ] 右键另一资源、查看历史、改显示色阶均不改变活动处理输入；对象菜单在切项目/测线/对象后失效。
- [ ] 参数修改在“应用”前不写草稿；Esc/关闭丢弃；切节点/输入/测线/项目对未应用变更防错写；相同算法/同名节点不串写。
- [ ] 草稿按数据身份隔离；运行冻结源锁定；失败/取消保留；成功只清提交源草稿；其他结果可浏览。
- [ ] 关闭全部后迟到预览不补开；切页/切源后任务完成不抢焦点；预览错误与重试对应真实源。
- [ ] A→B→C 后从 A 得 D，树中 B 与 D 同级；不可读取内部步骤不伪造成果；旧来源缺失显示待核对。
- [ ] 历史另建分支/重配、非空草稿替换确认与恢复、依赖删除、运行祖先保护全部保留。
- [ ] 部分成功明确实际已保存资源；未知/无能力操作禁用并给原因，不显示假成功。
- [ ] 完整键盘完成主导航、选择输入、添加/排序节点、参数应用/丢弃、运行/取消、tabs拆分及上下文菜单；焦点恢复正确。

### 9.3 科学与工程边界

- [ ] 固定真实数据和参数核对美术改造前后的处理输出、坐标、单位、色阶与导出语义；显示变化不生成处理步骤。
- [ ] 大数据预览仍按需分块/mmap，切换可见对象不导致完整矩阵复制；界面响应与长期运行内存另以测量记录。
- [ ] 项目导入、任务、解释、空间、成果链在 Windows 目标机走真实路径；截图和离屏 smoke 只证明部分外观，不代替桌面交互和真实数据验证。
