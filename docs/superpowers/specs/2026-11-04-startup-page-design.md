# MyGPR 启动页设计提案

2026-11-04，用户已确认精简方向，并授权深浅主题齐备后直接实施。范围为未打开项目时的启动界面；先实现下述首轮范围，后续独立功能仍保留为提案。

## 设计意图

把启动页组织成一个便于继续工作、整理项目与处理失效路径的项目启动台。视觉采用浅灰底、石墨色文字、蓝色操作强调，支持深色主题。以项目名称、路径和可用状态建立层次，降低大片空白和单列列表的视觉单调。

采用双区域布局、单击查看详情、双击或 Enter 打开，以及无项目时精简导航。PyQt6 / qfluentwidgets 为实施基础。

用户本轮明确要求减少次级标签和说明，由布局表达用途。界面保留项目身份、操作、路径和必要错误信息。操作提示使用工具提示与无障碍名称，辅助文案按需显示。

## 当前源码依据

- `ui/pages/home_page.py` 的 HomePage 在 ProjectPage 内显示。内容有标题、打开/新建按钮、最近列表和错误提示，列表限制最大高度 280。
- 最近项目已有固定、取消固定、复制路径、从列表移除功能，主要位于右键菜单。项目名称可来自 `project_display_names`，历史列表保存于 `recent_projects` 与 `pinned_recent_projects`。
- 当前单击和激活列表项都会发送打开信号。目录可用判断使用 `Path.is_dir()`，目录存在不能证明项目格式有效。
- `ui/main_window.py` 根据项目状态禁用处理、解释、空间和成果入口。无项目时隐藏资源树。`_restore_last_project()` 已自动尝试打开最近的可访问目录。
- `ui/coordinator_project.py` 承接打开/创建/关闭、操作忙碌和错误回包。首页信号保持由该链路执行。

## 推荐构图

整体以桌面逻辑宽度 1200–1440 为设计目标。启动内容内的左栏约 200–220，主栏弹性伸缩，项目详情约 240–280。视觉示例按对话可用宽度压缩展示。

- 顶部保留应用身份和原生窗口控制。无项目时采用轻量导航，设置入口始终可达。正常打开项目后展示现有七页工作台导航。任务页若有实际活动任务或故障需保持可达，建议放入左上角应用菜单。
- 左栏包含打开项目、新建项目、最近打开、已固定、设置。应用名称仅在顶部显示一次。
- 主栏包含简短标题、搜索框和项目列表。每行优先显示项目名，下一行显示路径，右侧提供始终可见的固定按钮。
- 右栏直接展示完整项目名、路径和打开按钮。异常时显示具体原因与恢复操作。
- 首次使用时隐藏搜索、列表和详情，主区域显示“还没有项目”和创建按钮。已有项目可通过左栏打开。

## 美术规范

浅色背景建议 `#F5F6F8`，列表区域以留白和行间距分组，选中行使用低饱和蓝底。主按钮使用 `#2458D3`。正文建议 `#202B3A`，辅助文字建议 `#647286`。深色使用 `#14171C` 背景、`#1D2128` 面板和明亮的文本，语义色同时配合文字。

字体沿用系统中文与 Segoe UI，主标题约 28–30 逻辑像素，项目名 14–15，辅助文字 12–13。按钮约 38–42 高，项目行约 72–80 高，圆角 6–10。品牌区允许少量抽象层状线条。图标采用统一细线风格，实际落地优先使用现有 FluentIcon。

首页首次显示阶段只读取设置中的项目目录信息。项目图形标识只用于区分列表项。

## 交互与功能范围

### 首轮推荐实施

1. 搜索名称与路径，大小写不敏感，基于现有最近列表过滤。无结果显示清空搜索入口。保留当前最近列表条数上限。
2. 固定按钮显式显示，沿用当前持久化字段和固定项优先排序。移动焦点和固定操作均保留选中项目身份。
3. 单击选中并显示详情，双击或 Enter 打开。提供明确的打开按钮。右键菜单和 Shift+F10 提供同一组操作。
4. 目录检查中显示紧凑进度，路径不可访问和打开失败显示原因。常规可访问状态通过可用操作体现。项目格式与占用情况由现有正式打开链路确认。
5. 首次使用、搜索无结果、打开中、路径失效四类状态有对应布局。打开中针对正在打开的项目显示进度并禁用重复提交。切换选择不会发起打开。
6. 新建入口继续使用现有新建项目对话框和字段。示例只展示名称与位置的主要部分，正式界面的可选项目详情使用渐进展开。

### 后续独立功能

- 重新定位项目。用户选择新目录后校验稳定项目身份，匹配后一次性更新最近列表、固定状态与名称映射，并去重。旧项目缺少稳定身份时提供“作为另一个项目打开”，由用户确认后添加新记录。失败或取消保留旧记录。文件选择、身份解析和项目打开共用现有控制器与任务约束。实施前核实当前项目格式是否提供稳定 ID。
- 拖入项目文件夹或 `project.json`。只接受一个本地项目目录，文件入口解析至所属目录。输入无效时给出明确错误，使用相同打开链路。拖入普通雷达文件时提示先创建/打开项目并导入。
- 启动偏好。新增 `startup_restore_last_project` 布尔项，缺失时默认 true，保持现有用户的自动恢复习惯。false 时停留启动台。用户点击关闭当前项目后停留启动台，不再次自动恢复。

以上后续功能出现在概念示例中供评审，均属于拟新增能力。搜索、固定和选中详情在示例内部可操作。创建、打开、重新定位仅演示流程，并显示“流程示意”。

## 状态、线程与兼容

- 保留 ProjectPage 的 startup / empty / ledger 状态，由同一状态入口切换展示。项目打开成功后进入空项目引导或已有测线台账。
- 保留 `homeInterface` 兼容路由和 HomePage 对协调器暴露的信号。项目页、设置页、输出面板的现有职责继续由原有对象承接。
- 首屏立即显示缓存的名称/路径，状态先为待检查。目录可访问检查在工作线程中执行，避免断开的外置盘和网络路径阻塞 Qt 主线程。不得在启动页遍历测线数组或全量校验 HDF5。
- 回包带路径身份和请求代次。刷新列表、移除项目或关闭启动页后忽略过期结果。正式打开前仍走现有写锁、只读模式、版本兼容、活动任务和未保存解释检查。
- 新设置通过共享 SettingsManager 保存，读取失败时遵循现有保存保护。新增字段与历史设置兼容，原有路径/名称字段保持可读。
- 关闭当前项目后的启动台选择最近记录，不自动触发打开。自动恢复失败时显示路径与原因，允许用户手动打开其他项目。

## 响应式与无障碍

宽窗口显示列表与详情并列。中等宽度将详情放到列表下方。窄窗口将左栏动作收为上方双按钮，次要路径省略但可查看全文。以实际控件最小宽度和 DPI 计算断点。交互示例覆盖 320、768、1024 宽度，Qt 实施需另行核对 100%、150%、200% DPI。

Tab 可访问主动作、搜索、项目项、固定与详情按钮。项目名的完整文本可被辅助功能读取。Enter 打开，Esc 关闭弹层并恢复触发控件焦点。错误同时提供文字与操作入口。

## 预计代码落点

- `ui/pages/home_page.py` 负责启动内容组织、项目选择和空状态。必要时将重复项目行抽为 `ui/widgets/recent_project_list.py`，采用现有项目路径作为身份。
- `ui/main_window.py` 负责 startup 状态下导航呈现与启动偏好读取。
- `ui/coordinator_project.py` 与 `ui/controllers/project_controller.py` 负责打开、目录探测及重新定位请求回包。后续功能按独立切片增加。
- `ui/settings_manager.py` 增加启动偏好默认值，沿用已有最近列表及固定字段。
- 视觉参数进入现有 `ui/design_tokens.py` / `ui/constants.py`，避免页面私有配色扩散。

现有设置文件保护修复是本聊天前一轮维护的未提交改动。设计实施前须核对并保留其归属。

## 验收条件

- 最近列表为空、仅固定项、全部路径失效、长中文名称、长路径、搜索无结果、后端未就绪和打开失败均有可操作状态。
- 选择、搜索、固定、移除不会隐式打开项目。打开按钮、双击和 Enter 每次只产生一个打开请求。
- 移除仅更新最近列表。重新定位取消、身份不匹配和失败时保留旧记录。重复路径合并规则覆盖固定与名称映射。
- 明暗主题、小窗口和高 DPI 下正文与按钮完整可读。原生快捷键与窗口控制正常。
- 首屏、首次打开与退出耗时分别记录，异步目录检查不阻塞界面，迟到回包不更新错误项目。
- Qt 回归默认交由 GitHub CI。实际桌面焦点、DPI、文件拖放与目录选择需 Windows 交互验收。
