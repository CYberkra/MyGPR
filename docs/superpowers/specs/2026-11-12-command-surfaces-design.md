# MyGPR 设置、菜单与弹层整理方案

2026-11-12，设计稿。盘点基线为 `b6a21d5`。从处理页开始，覆盖七页的同类入口。本文的菜单和交互规则为拟实施设计。

## 1. 当前入口与问题

| 入口 | 当前行为 | 需要解决的问题 |
| --- | --- | --- |
| 待执行链右侧 `+` / `…` | `+` 打开方法选择器。`…` 提供添加、编辑、复制配置、恢复上一个草稿和查看失效草稿 | 添加有两个入口。编辑某一步和管理整份草稿混在一起 |
| B-scan 标题栏的 `标记 ▾` | 显隐、列表、新增点、新建区间、导出带标记图件 | 新增点的编辑初值来自当前成果第一个道索引；用户需要先明确位置。图件出口与画布右键分散 |
| B-scan 标题栏的齿轮 | 跳到设置页的全局 B-scan 设置。画布和视图组菜单也有入口 | 从某张图进入却切走工作区，图内临时状态与应用偏好难以区分 |
| 齿轮旁方框、图内斜箭头 | 方框执行 `fit_to_data()`，图内斜箭头进入全屏。适应视图会解除比例锁定、清框选并发出全局比例变更信号 | 两个图标容易混淆。一个看似局部的命令可写回应用比例偏好 |
| B-scan 标题栏 `…` 与标签右键 | 共用大部分菜单，包含框选转处理、联动、固定、分组、关闭、来源和全局设置 | 组布局、单个成果、画布选择三种目标混合。来源还需要打开另一层菜单 |
| B-scan 图面右键 | 框选、缩放、查看时窗、全屏、读数、A-scan、显示模式、显示增益、图像导出与显示设置 | 局部查看和可持久化显示增益同列。画布走 pyqtgraph 鼠标事件，标签走 Qt 右键与键盘入口 |
| 待执行步骤右键 | 选中步骤并直接打开参数编辑器 | 用户无法先查看步骤操作。隐藏的步骤列表还保留一套旧右键定义 |
| 标记列表右键 | 原生 `QMenu`，混合定位、编辑、建区间、处理、跨页、清单导出与项目时区 | 取已有选中行，命中行与目标可能不同。整表和项目命令占用对象菜单 |
| 其他页面 | 已有 Fluent 菜单、对象绑定和部分手写右键。设置页保留文本编辑控件的默认菜单 | 需沿用稳定目标与菜单生命周期的现有实现，并统一例外入口的规则 |

现有合同见[工作台](2026-10-16-workbench-redesign.md)、[标记与事件区间](2026-11-11-marker-event-contract.md)和[永久删除](2026-11-04-deletion-interaction-design.md)。

## 2. 入口分工

| 入口 | 用户要做的事 | 例子 |
| --- | --- | --- |
| 直接按钮 | 执行当前流程中高频且明确的操作 | 添加步骤、从当前输入运行、适应全图、全屏 |
| 带文字下拉 | 进入一个明确的功能组 | 标记、导出、项目切换 |
| 齿轮 | 查看和更改当前视图的显示项 | 显示模式、十字读数、A-scan 跟随 |
| `…` | 执行其所在栏的低频命令，或承接该栏因宽度移入的按钮 | 草稿操作、视图组操作、列表操作 |
| 右键 / `Shift+F10` / `Menu` | 对命中的图、标签、步骤、记录或文件操作 | 标签固定、编辑步骤、定位标记、复制标识 |
| 弹层或对话框 | 输入参数、比较预览、确认数据变更或展示可复制详情 | 参数编辑、区间选道预览、永久删除确认 |
| 设置页 | 保存跨会话的应用偏好 | 主题、默认横纵轴、比例策略、色图、色阶、全局显示增益 |

鼠标右键和可见入口可以复用同一条命令。直接按钮保留常用操作，右键提供就地使用，`…` 补足低频操作。菜单里只放命令、开关、互斥选项和一级子菜单。滑条、数值输入、格式选择、校验说明使用相应表单。依据：[Microsoft Windows 菜单与上下文菜单](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/menus-and-context-menus)、[Qt QAction](https://doc.qt.io/qt-6.11/qaction.html)。

## 3. 处理页的具体菜单

```text
待执行      [去直流] [带通] [+] […]
成果标签    [原始输入] [带通结果]                 [标记 ▾] [显示 ⚙] [适应全图] […]
                                                           图内右上角 [全屏]
```

### 待执行步骤与草稿

| 入口 | 菜单内容与顺序 | 操作结果 |
| --- | --- | --- |
| `+` | 打开可搜索的方法选择器，支持连续添加 | 追加到当前输入的待执行链 |
| 方法选择器／方法库 | 条目可添加到处理链或复制方法名。分类与搜索用于定位方法 | 添加使用当前草稿入口，方法身份以注册 ID 为准 |
| 待执行链 `…`（草稿操作） | 复制待执行配置；恢复此输入的上一个草稿；有失效记录时提供查看旧修订草稿 | 作用于整份草稿，读取和恢复均按输入身份及修订 |
| 步骤左键 / Enter | 打开参数编辑器 | 应用前保留原值。Esc 或关闭取消未应用修改 |
| 步骤右键 / 键盘菜单 | 编辑参数…；启用或停用；复制步骤；上移、下移；替换方法…；从草稿移除 | 作用于命中步骤。替换须明确应用。移除仅变更待执行配置 |
| 步骤链空间不足 | 已折叠步骤列表，选中一项后可使用同一组步骤命令 | 列表按执行顺序显示，保持步骤 ID 与启停状态 |
| 已完成来源 / 历史运行 | 来源节点显示参数与来源、打开或设为输入、按真实上游另建分支；历史运行显示最终成果、已保存步骤、冻结输入、复制记录和按原输入配置 | 只有明确执行重配才替换草稿。来源不完整时给出禁用原因。运行仍由主按钮提交 |

步骤编辑器只承接参数与方法选择。直接操作如启停和移动用同一执行函数供菜单、键盘和已有控件调用。替换非空草稿走现有确认与备份恢复。已完成来源与待执行链分别读取其现有模型。

### B-scan 的显示、画布与标签

| 入口 | 菜单内容与顺序 | 作用域 |
| --- | --- | --- |
| 齿轮（当前图显示） | 显示模式（沿用现有枚举）；十字光标读数；A-scan 波形跟随；全局 B-scan 设置… | 前三项即时影响当前图。最后一项进入设置页对应区块，返回原页时保留原上下文 |
| 适应全图按钮 | 一键显示当前图全部有效范围，恢复完整查看时窗，清除仅用于框选放大的临时范围 | 保留当前比例策略。缩放平移可按已启用的兼容视图联动传播。既有事件区间和项目记录保留 |
| 图内全屏按钮 / F11 | 全屏当前图。全屏保留适应全图和退出按钮，画布菜单可用 | 同一视图的显示、选择与退出状态。退出返回原视图组 |
| 图面右键 | 框选放大、适应全图、全屏；查看时窗（现有预设、自定义、恢复完整时窗）；当前图显示…；复制图像、导出图件… | 只指向右键命中的图。时窗仅控制查看的回波纵轴，有效时间轴可用时提供 ns 选项 |
| 图面右键，已有有效框选 | 增加“将框选加入处理草稿”，子菜单提供测道裁剪、坏道标记、道与时间裁剪 | 沿用各方法的现有输入条件，明确加入的是待执行步骤。提交前保留原数据。无可靠纵轴时间时禁用道与时间裁剪 |
| 图面右键，命中有效道 | 增加“在此道新增点标记…”，使用该成果与列号进入标记表单 | 屏幕位置经当前 ViewBox 变换、当前成果校验后生成沿线锚点 |
| B-scan 标签右键 | 参数与来源…；设为处理输入；按此步参数另建分支…；预览失败时提供重试；固定标签；分组布局（拆分、移动或复制）；关闭标签、关闭范围（其他／右侧未固定标签） | 绑定命中的标签、视图组和数据版本。原始输入、对比预览、持久成果各按实际能力显示 |
| B-scan 标题栏 `…`（视图组操作） | 列出本组已打开标签；视图联动；关闭本组未固定标签；重新打开已关闭标签；恢复为单组 | 组布局或工作区状态。标签列表可搜索或滚动，长名称支持查看完整值 |

适应全图由独立的视口命令实现。现有 `fit_to_data()` 的全局比例变更路径继续服务明确更改比例的操作。恢复时窗只重置纵向范围，保留横向位置。启用联动前沿用现有来源和物理轴兼容检查。快捷键从当前焦点确定视图，跨组切换后重新计算目标。

显示设置页继续管理全局轴单位、比例、色图、对比度、色阶、色标、QC 标记和显示增益。TVG 参数编辑从全局显示增益区进入，界面明确“应用到全部 B-scan”。应用时同步已打开、全屏和后续创建的视图，设置页读回同一持久值。A-scan 跟随走单独的读道交互，解释拾取由解释页工具控制。切换或关闭波形跟随时保留用户的拾取模式。

齿轮和“当前图显示…”复用同一轻量弹层。锚定原工具栏或图面调用位置。显示模式用一组互斥选项，十字读数和 A-scan 用两个开关，底部链接全局设置。即时变更保留，Esc 关闭弹层。适应、框选、查看时窗和全屏的命令仅在可用数据与相应模式下启用，缩略预览按其已有交互能力呈现。

| 状态 | 所属对象 | 保存及恢复 |
| --- | --- | --- |
| 显示模式、十字读数、A-scan、标记条可见 | 当前 B-scan 视图 | 在同一视图的全屏进出及短暂遮挡时保留，应用设置文件不记录这些临时覆盖 |
| 缩放、平移、查看时窗、临时框选 | 当前视图及其绑定的成果 | 切换成果后按已有会话恢复规则处理。临时框选随源修订失效 |
| 视图联动、分组、固定标签 | 处理工作区 | 由工作区维护，使用已有恢复边界 |
| 轴单位、比例、色阶与显示增益 | 应用 B-scan 偏好 | 由设置管理器写入并同步各视图；应用读到统一值 |
| 项目时区、点标记、事件区间 | 项目 | 由项目控制器保存。图面显示命令只读取相应项目数据 |

图件使用统一入口，按当前视口提供复制图像、PNG 导出以及“包含可见标记”选项。导出界面冻结成果和显示状态，文件对话框返回后验证来源。成果矩阵、数据文件和交付包使用成果页的导出能力。永久删除处理成果由项目资源或成果表发起，标签继续提供关闭视图。

### 标记入口与选道处理

| 入口 | 菜单内容与顺序 | 操作结果 |
| --- | --- | --- |
| `标记 ▾` | 显示标记条（勾选）；打开标记列表；新增点标记…；新建区间… | 绑定当前图。新增点进入选道或显式输入；新建区间沿用标记条选取两端。保存提交项目记录 |
| 胶囊右键 / 标记表行右键 | 定位、详情或编辑…；区间可调整范围；源标记可排除使用或恢复使用；项目记录可删除…；可定位时显示跨页入口 | 用同一记录 ID，按对象来源、映射状态和权限显示。普通左键选中，双击打开详情 |
| 标记条 `+N` | 当前聚合成员列表 | 选中成员后高亮，保持横轴标题与胶囊共用单行 |
| 标记列表工具栏 | 两个点时提供建立区间；处理页选中闭合且可用的区间时提供保留／剔除；`导出 ▾` 提供 CSV、JSON、GeoJSON | 导出注明当前测线、筛选结果或项目范围。空间清单显示未定位数量 |
| 项目元数据 | 项目时区… | 作用于项目的采集时刻显示，逐道时间基准和事件锚点继续由现有数据约束决定 |

保留／剔除在处理页使用独立预览，展示输入成果、合并后实际道数、预计输出道数与断点，再由用户确认提交。解释页、空间页的标记记录可用“在处理页查看”进入同一流程。未闭合、无采集道、来源失效、需复核或混用成果版本时显示具体原因，并由范围服务复核。采集时刻选择和图面 ns 时窗保留独立入口。

| 页面和对象 | 可见入口及右键命令 | 边界 |
| --- | --- | --- |
| 项目切换与最近项目 | 左上项目菜单负责新建、打开、切换、关闭，末组提供永久删除当前项目。最近项目行提供打开、固定、复制路径、从最近列表移除，以及分隔后的永久删除 | 最近记录移除只改列表。永久删除进入已有确认流程 |

| 空间信息页 | 地图背景右键提供适应全部测线、放大／缩小、复制此处坐标、导出视图。测线或图层命中菜单提供定位、显隐、设为当前。瓦片下载放在底图工具里，明确当前区域；3D 图面放重置视角、视角预设、地形／网格和截图；深度切片沿用查看与导出命令 | 地图坐标带坐标参考，地图中心与点击位置用准确名称。缺少几何时定位禁用。图层显隐、卸载与持久成果删除分别执行 |
| 成果页 | 成果行提供参数与来源、设为当前版本、打开目录、导出及永久删除；报告路径提供复制路径和打开目录。工具栏保留生成报告、导出成果包及清单 | 打开、导出、删除均按命中的版本。报告和成果包继续冻结快照 |
| 任务页 | 任务行提供详情、复制任务标识／当前消息、取消任务。清理终态记录放在任务列表工具栏 | 取消按钮依据实时状态。现有无执行能力的通用重试和单项移除退出菜单，待作业层具备相应语义再提供 |
| 设置页 | 主题、B-scan、处理、存储和关于留在各区块。文本输入保留系统剪切、复制、粘贴与撤销菜单 | 应用设置持久化后同步控件。已失效的设置值按现有默认值修复，项目级设置从项目入口进入 |

## 5. 鼠标、键盘和状态规则

1. **先确定目标。** 鼠标菜单按命中对象解析。已有多选中右键某个选中行时，多对象命令使用这批 ID；右键未选中行时，命令使用该行 ID。单对象命令始终使用命中行。空白只呈现区域命令。菜单打开和取消保留原选中项、活动输入及解释状态。
2. **按焦点选择菜单。** `Shift+F10`、`Menu` 在标签上指向当前焦点标签，在列表指向焦点行，在画布打开当前视图菜单。在画布通过键盘打开且没有明确列坐标时，位置动作进入选道或道号输入。文本编辑器消费自己的菜单与常用编辑快捷键。方向键、Enter 和 Esc 作用于最内层活动控件；取消后焦点回到原入口或仍存在的近邻。
3. **分派一次。** 参数编辑、框选、区间创建／调整、解释拾取均有明确活动状态。框选期间右键或 Esc 先取消手势，避免同一次点击再弹菜单。未保存的标记调整提供保存／取消。正常浏览时只弹命中的最具体菜单，避免图面与图元同时响应。Qt 分辨鼠标和键盘事件，pyqtgraph 菜单开关可分别控制 PlotItem 与 ViewBox。依据：[Qt QContextMenuEvent](https://doc.qt.io/qt-6.11/qcontextmenuevent.html)、[pyqtgraph 0.14 PlotItem](https://pyqtgraph.readthedocs.io/en/pyqtgraph-0.14.0/api_reference/graphicsItems/plotitem.html#setMenuEnabled)。
4. **冻结目标并复核。** 打开菜单时捕获适用的项目、测线、成果及版本、步骤／标记／任务 ID、选区和视图组。执行前重查目标、权限和任务状态。排序、切页、切测线、源修订、对象删除、模式退出时，关闭失效菜单或明确提示对象已变更。异步操作提交后以冻结 ID 回填结果。
5. **用状态表达可用性。** 当前对象没有该类能力时省略。用户可能补齐条件时保留禁用项及短原因，例如“需真实 ns 时间轴”“项目只读”“区间需复核”。只读项目允许查看、定位、复制与有效导出。参数、草稿、项目元数据、任务与文件命令分别做各自权限检查。永久删除复用现有预检与确认，最终动作写明对象和范围。
6. **统一状态与样式。** 开关用勾选，互斥模式用单选状态。tooltip 和无障碍名称写“草稿操作”“视图组操作”“适应全图”“全屏浏览”，不用图标名称。沿用 Fluent 主题令牌、字号、间距与焦点样式。窗口变窄时保留主动作，次要动作进入所在栏的 `…`，保持两条原有工具栏和单行标记。菜单贴近按钮或指针，在当前屏幕工作区内翻转或滚动。

## 7. 验收场景

- 两组对比 B-scan 分别使用不同成果。右键非活动标签不切输入。适应全图保留既有比例，联动关闭时另一组不动。仅在明确执行“设为处理输入”后换草稿上下文。
- 框选后“加入处理草稿”绑定正确图与数据版本。切换输入或更新预览后旧菜单无效。无真实时间轴时不生成道与时间裁剪步骤。
- A-scan 跟随开关、关闭波形窗、全屏进出均保留解释工具状态。切显示模式、切图、切主题和重启后，局部状态和全局设置按定义恢复，色图等改动不提交任务。
- 对不同步骤和同名草稿执行编辑、移动、替换及 Esc。只改命中的稳定步骤，旧菜单和异步回调不应用到新步骤。
- 在标记表右键未选中行、已选多行、排序后行和空白。定位、编辑、处理预览作用于正确集合。只读项目浏览和导出可用。无定位或需复核区间有明确原因。
- 区分“关闭标签”“从最近列表移除”“从解释移除”“永久删除成果”。取消均保留对象，永久删除复核真实依赖和正在运行的任务。删除文件范围遵守现有合同。
- 比较鼠标、可见按钮、`Shift+F10`、`Menu` 入口。菜单关闭后恢复焦点，文本框原生菜单可用；反复开关、确认取消、跨页、关闭窗口后无残留菜单或二次触发。
- Windows 浅色／深色，100%、150%、200% DPI，窄窗、双屏边缘、多视图及全屏。检查长名称、省略、禁用原因、菜单可读性和标记单行高度。自动化回归在 GitHub Actions 执行，原生交互单独记录。
