# 无界面批处理

服务器 / SSH / 自动化脚本场景，不开 GUI 完成全部工作。两条路径：`cli_batch.py`（配置驱动批处理）与 `MyGPRBackend`（编程 API）。

## cli_batch.py

### 1. 编写作业配置

```json
{
  "jobs": [
    {
      "id": "line3-demo",
      "input": "sample_data/uav_gpr_motion_demo_v1/main.csv",
      "methods": [
        {"key": "dewow", "params": {"window": 23}}
      ]
    },
    {
      "id": "line9-custom",
      "input": "sample_data/uav_gpr_motion_demo_v1/main.csv",
      "methods": [
        {"key": "set_zero_time", "params": {"new_zero_time": 5.0}},
        {"key": "dewow", "params": {"window": 23}},
        {"key": "fk_filter", "params": {"angle_low": 10, "angle_high": 60, "taper_width": 5}}
      ]
    }
  ]
}
```

- `methods`：逐算法显式指定（每项 `{"key": 算法, "params": {...}}`；参数缺省取算法默认）。**`recommended_profile` 预设档已在 0.9.38 移除**，旧配置会校验报错——请改用显式 methods 列表。
- CLI 输入支持 CSV/TXT 和 H5/HDF5；CDUT 采集 HDF5 使用嵌入传感器元数据，外部传感器需另行显式同步。
- 无人机 CSV 可附 `"trace_timestamps_s": [...]` 与 `"rtk_path"/"imu_path"/"altimeter_path"` 做传感器同步。

### 2. 校验与执行

```bash
python cli_batch.py validate --config myjobs.json   # 不落盘，只校验
python cli_batch.py run --config myjobs.json        # 执行
```

输出目录每作业一个子目录：逐步 `<序号>_<算法>.csv/.png`、`final.csv`、`final.png` 与作业摘要。

## 编程 API（MyGPRBackend）

适合嵌入既有 Python 流程。使用 `submit_*` 提交的操作走任务系统（`submit_* -> job_id`，`backend.jobs.wait(job_id)`）：

```python
from pathlib import Path
from uuid import uuid4
import numpy as np
from mygpr.interfaces.backend import MyGPRBackend
from mygpr.domain.processing.models import PipelineDefinition, PipelineStep
from mygpr.application.jobs.models import JobStatus

# 独立示例项目保存在 output/，每次运行使用新目录。
root = Path("output/api_demo") / uuid4().hex
backend = MyGPRBackend.create_default(max_workers=1)
try:
    project = backend.projects.create_project(root, name="demo")
    backend.projects.save_line_dataset(
        project.project_id, "L01", np.zeros((48, 16), dtype=np.float32),
        length_m=15.0, time_window_ns=200.0,
    )
    pipeline = PipelineDefinition(name="demo", steps=(PipelineStep("dewow", {"window": 11}),))
    job = backend.submit_project_pipeline(project.project_id, "L01", pipeline)
    result = backend.jobs.wait(job, timeout=30)
    assert result.status is JobStatus.COMPLETED, result.error_message
    backend.projects.close_project(project.project_id)
finally:
    backend.shutdown()
```



空间成果前置条件（轨迹 + 已确认标注）与 GUI 相同；标注经 `backend.projects.save_interface_annotation` 提交。

## 注意

- 无显示环境 matplotlib 自动走 Agg 后端，报告/图件渲染不受影响；管线模块不 import Qt（有测试钉住）。
- 定时自动备份：用系统计划任务（cron/任务计划程序）调度上面的备份调用即可，后端不内置调度器。
