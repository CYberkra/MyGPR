# 无界面批处理

服务器 / SSH / 自动化脚本场景，不开 GUI 完成全部工作。两条路径：`cli_batch.py`（配置驱动批处理）与 `MyGPRBackend`（编程 API）。

## cli_batch.py

### 1. 编写作业配置

```json
{
  "jobs": [
    {
      "id": "line3-demo",
      "input": "data/Line3origin(36).csv",
      "recommended_profile": "robust_imaging"
    },
    {
      "id": "line9-custom",
      "input": "data/Line9origin(36).csv",
      "methods": [
        {"key": "set_zero_time", "params": {"new_zero_time": 5.0}},
        {"key": "dewow", "params": {"window": 23}},
        {"key": "fk_filter", "params": {"angle_low": 10, "angle_high": 60, "taper_width": 5}}
      ]
    }
  ]
}
```

- `recommended_profile`：预设档展开（`robust_imaging` / `high_quality_uav_gpr` / `hankel_denoise` / `wavelet_2d_denoise` / `motion_compensation_v1` 等 10 个），或 `auto` 按数据头自动选。
- `methods`：逐算法指定；参数缺省值取算法默认。二选一，不能混用。
- 无人机 CSV 可附 `"trace_timestamps_s": [...]` 与 `"rtk_path"/"imu_path"/"altimeter_path"` 做传感器同步。

### 2. 校验与执行

```bash
python cli_batch.py validate --config myjobs.json   # 不落盘，只校验
python cli_batch.py run --config myjobs.json        # 执行
```

输出目录每作业一个子目录：逐步 `<序号>_<算法>.csv/.png`、`final.csv`、`final.png` 与作业摘要。

## 编程 API（MyGPRBackend）

适合嵌入既有 Python 流程。全部耗时操作走任务系统（`submit_* -> job_id`，`backend.jobs.wait(job_id)`）：

```python
from mygpr.interfaces.backend import MyGPRBackend

backend = MyGPRBackend.create_default(max_workers=2)
try:
    project = backend.projects.create_project("d:/work/demo", name="demo",
                                              coordinate_system="CGCS2000 / 3-degree GK zone 36")
    backend.projects.import_line_source(project.project_id, "L01", "data/Line3.csv")

    job = backend.submit_pipeline(
        backend.projects.read_dataset(project.project_id, "L01").data,
        pipeline,                       # PipelineDefinition：PipelineStep 列表
        header_info={"total_time_ns": 700.0},
    )
    result = backend.jobs.wait(job, timeout=600)

    backend.submit_spatial_result(project.project_id, name="r1", line_ids=["L01"])
    backend.build_georeference_3d(project.project_id, "L01")
    backend.submit_project_report(project.project_id)
    backend.submit_project_backup(project.project_id, incremental=True, retention_keep=10)
finally:
    backend.shutdown()
```

空间成果前置条件（轨迹 + 已确认标注）与 GUI 相同；标注经 `backend.projects.save_interface_annotation` 提交。

## 注意

- 无显示环境 matplotlib 自动走 Agg 后端，报告/图件渲染不受影响；管线模块不 import Qt（有测试钉住）。
- 定时自动备份：用系统计划任务（cron/任务计划程序）调度上面的备份调用即可，后端不内置调度器。
