# 标记与事件区间

在处理页或解释页打开测线，使用 B-scan 顶部的“标记”菜单。标记条位于横轴下方。
点标记记录位置；事件区间记录一段采集过程或沿线范围。保存记录不会改变波形。

## 记录现场情况

| 情况 | 建议记录 | 需要核对 |
| --- | --- | --- |
| 停车且继续采集 | 停车等待区间 | 实际重复道、车辆反射及恢复后的第一条正常道 |
| 停车且暂停采集 | 采集时刻区间，道号留空 | 没有采集道时仅保存事件 |
| 行进中有车辆经过 | 外部干扰区间 | 结合波形修订影响范围 |
| 已知防空洞起止 | 目标范围区间 | 信息来源填写现场记录或既有资料 |
| 从波形推测目标范围 | 目标范围区间 | 信息来源填写雷达判读，复核后关联解释对象 |
| 单个地物或操作位置 | 点标记 | 道号、名称及备注 |

用途可直接输入自定义文字。同名记录、同道记录和重叠区间分别保存。

## 创建和修改

1. “标记 → 新增点标记”打开详情。输入道号、名称和备注后保存。
2. 新区间可在标记条连续点击两个边界，也可在列表选两个点后执行“建立区间”。详情内同样可以直接输入起止道号。
3. 默认包含两端道。“恢复运行”落在第一条正常道时，可取消“包含结束道”；软件不会根据标签文字替你判断。
4. 点击标记只选中并高亮。双击打开详情。“调整范围”才允许拖动边界；松开后在详情中保存或取消。
5. 未闭合区间允许保存。它不能参加保留或剔除处理。

“标记列表”显示名称、用途、位置或范围、状态。可搜索名称及备注，筛选点、区间、用途、可定位或已排除记录。
列表可切换当前测线和整个项目。方向键选择，Enter 定位，F2 打开编辑。快捷键仅作用于列表。
密集标记显示数量，点击数量打开成员列表。隐藏标记条不会删除记录。

采集记录可以修订显示名称、填写备注、排除使用和恢复使用。原始采集字段保留在详情中。
项目新增记录可删除；存在区间或解释引用时须先解除关联。标记操作不会删除采集文件。
保存失败时编辑窗口保留内容，可修正后重试。
详情将“采集时刻”“关联解释”和“来源与记录详情”折叠显示；点击标题展开。
表单可以滚动，保存和取消始终位于窗口底部。

## 时间和位置

- **采集时刻**是现场采集这一道的日期时间。
- **测线位置**是沿线距离或道号。
- **双程走时**是单道内部回波的时间，通常以 ns 显示在纵轴。

停车时间段使用采集时刻或道号区间。“时间窗裁剪”修改纵轴，不能用来删除停车过程。
列表“操作 → 项目时区…”设置显示时区，例如 `Asia/Shanghai`。默认 `UTC`；保存值仍为 UTC。
时间输入必须带时区，例如 `2026-11-11T14:32:00+08:00`。

只有可靠、同一时间基准且没有回跳的逐道采集时间才能自动选道。缺少这些信息时保存事件，但按道号选择数据。
采集标记时间与逐道采集时间分开显示；两次标记的时间差称为“标记间隔”。
时间区间没有匹配道时显示“期间无采集道”，不会吸附到相邻道。

## 保留或剔除

1. 激活要处理的原始数据或已保存成果标签。
2. 在列表选中一个或多个闭合区间。
3. 执行“保留所选区间”或“剔除所选区间”。
4. 核对输入、合并后的实际道范围、输出道数及分段数，点击“运行并生成新成果”。

操作只按确认范围选道，不附加自动异常检测。重叠范围取并集。不能生成零道成果。
无法映射、已排除、需复核或没有采集道的区间会阻止提交；需先处理这些记录或从所选集合移除。
结果保存原距离、时间、道映射和缺口。跨缺口或非等间距不满足算法要求时，软件拒绝该算法。
详情的“已执行”记录显示旧成果使用的区间版本。修改区间后，旧成果保持原状。

## 查看和交付

普通选择只同步高亮。使用“在处理页查看”“在解释页查看”“在空间页定位”切换页面。
解释关联选择已有对象。目标范围名称不会自动生成目标、界面、深度或地下轮廓。
地图使用实际轨迹片段；缺坐标、缺轨迹或来源不明时保留列表记录，不绘制猜测位置。

列表支持 CSV、JSON、GeoJSON；GeoJSON 只包含可定位记录，并给出无法定位数量。
CSV、JSON 保留完整记录，JSON 同时保存投影、空间来源和处理记录快照。
“导出带标记图件”保存当前 B-scan；工程报告和处理成果包包含生成时的标记快照。
防空洞区间的空间含义始终是“沿测线参考范围”。

## CLI

安装源码包后可用 `mygpr-markers`；也可用 `python -m mygpr.interfaces.cli.markers`。
GUI 和 CLI 使用同一范围解析与执行服务。接口道号从 **0** 开始，界面道号从 **1** 开始。

```powershell
mygpr-markers D:/projects/survey --line L01 list
mygpr-markers D:/projects/survey --line L01 save event.json --interval --revision 0
mygpr-markers D:/projects/survey --line L01 preview --id <区间ID> --mode exclude > preview.json
mygpr-markers D:/projects/survey --line L01 execute preview.json
mygpr-markers D:/projects/survey --line L01 export markers.json --format json
```

`save` 输入单条记录 JSON。修改记录须保留其 `uid` 和当前 `revision`；`--revision` 是文档修订号。
道锚点需使用 `list` 返回的 `source_id`。成果输入加 `--artifact <成果ID>`。
执行前核对预览文件。记录、源数据或输入成果变化后，旧预览会被拒绝。
