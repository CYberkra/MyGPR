# 生成报告与备份

## 报告包

成果页 → **生成报告包**（包名可留空自动命名）。产出自包含交付目录：

- PDF / HTML / Excel 三格式报告
- 工程图件（含 GIS 平面图渲染）
- 可追溯 CSV/JSON 数据表
- 文件审计与 SHA-256 校验和清单

报告内容按 profile 分节（可开关：界面标注、空间分析、钻孔对比等节）。生成走后台任务，任务页看进度。

## 备份

### 图形界面

成果页 → **备份当前项目**：

- **增量备份**（默认勾选）：只打包相对同目录最近一次备份**变化的文件**；恢复时自动合并基准链。
- **保留最近 N 个**：成功后自动清理最旧档案（默认 10）。

### 无界面

```python
backend.submit_project_backup(project_id, destination_dir, incremental=True, retention_keep=10)
```

### 规则

- 备份是带 SHA-256 清单的压缩包，**创建后立即做恢复式校验**，损坏档案当场报错。
- 正式灾难恢复勾选「必须使用外部设备」：目标与项目不同物理磁盘才执行。
- 增量恢复需要基准链完整：同目录的基准档案不可删除（删除后恢复报"缺少基准档案"）。
- 项目内符号链接、临时文件（`.transactions`/WAL/锁文件）自动排除。

## 恢复

成果页 → **从备份恢复** → 选归档 → 恢复为**新项目目录**（不覆盖原项目）。恢复完成后自动做只读完整性验证。

## 建议

- 每个关键节点（导入后、标注确认后、交付前）各做一次备份；日常用增量，里程碑用全量。
- 正式交付前把备份拷贝到与工作机不同的物理设备。
