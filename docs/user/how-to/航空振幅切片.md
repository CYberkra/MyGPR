# 航空振幅切片

> 适用当前开发分支。正式发行版是否包含此功能以发行说明为准。

1. 打开项目并导入测线。需要参与切片的测线应有逐道位置和已确认的坐标系；位置缺失的道不会被补造。
2. 在 **空间信息** 左侧勾选测线，切到 **振幅切片**。为每条测线选择原始输入或处理结果。
3. 设置采集时间窗、网格大小及 RMS、均值或最大振幅，点击 **生成切片**。参数变更后需要重新生成。
4. 平面图显示有观测的网格和测线点；空白不代表零振幅。点击有值网格可查看对应测线剖面。
5. 点击 **三维查看**，旋转或缩放地形和测线幕帘；点击幕帘可在侧栏查看对应 B-scan。底部滑条切换时间窗。
6. 点击 **保存成果**。在成果页右键该空间成果，选择 **查看振幅切片** 可重新打开，也可导出 ZIP 或 GeoTIFF。覆盖计数和来源记录包含在成果目录及 ZIP 中。

自动分量仅接受数据中明确声明的 `real`、`mag` 或 `magnitude`。对于无声明的普通数据，需按实际数据含义选择时域实部或时域幅值。`fdata` 为仪器显示采样，物理语义未确认时不能用于振幅时间切片。处理结果必须保留可映射回原始测线的逐道标识。

当前切片以采集时间为基准。航空高度、系统延迟、地表起伏和介质速度尚未在此视图中自动换算为地下深度。三维幕帘的垂直比例仅用于显示，不是地下深度；不同测线的色阶仅用于浏览各自剖面。稀疏航线之间不插值。切片和三维显示不能单独证明滑坡面位置。

三维视图可在“三维显示”中开关 T600 无人机示意。模型按首条有效测线的起点和轨迹方向摆放，并为看清轮廓放大；它不代表飞机的实际位置、航向、姿态或真实尺寸。

保存的结果与来源不一致时，软件只打开冻结的网格，并提示来源已变化。永久删除空间成果只删除 MyGPR 管理的成果文件，不删除最初导入的雷达或传感器源文件。
