# MyGPR v0.9.13 beta 用户手册

## 适用范围

v0.9.13 beta 面向现场勘探定位流程，主界面包括：项目管理、测线处理、目标定位、空间成果和成果报告。

## 基本流程

1. 在项目管理中新建或打开项目。
2. 导入测线数据，必要时批量导入。
3. 导入 RTK / IMU 等辅助定位文件。
4. 运行数据质检，若 B-scan 方向异常则执行方向修正。
5. 在测线处理页预览、应用并保存处理结果。
6. 在目标定位页新增、保存或辅助识别目标。
7. 在空间成果页刷新空间成果、导出坐标、生成平面图或打开三维视图。
8. 在成果报告页生成报告包或 PDF。

## 支持的数据

正式导入入口支持 CSV、TXT、NPY、NPZ、H5、HDF5。厂商原生格式需要专项样例测试后逐项开放。

## 空间成果

空间成果工具栏已接入：

- 刷新空间成果
- 导出坐标成果
- 打开三维视图
- 生成平面图
- 图层控制

三维视图可查看测线轨迹、目标点、平面图和数据汇总，并可导出 PNG 与三维点云 CSV。

## 成果报告

报告包包含 HTML、JSON、CSV 和 PDF。Excel 报告仍在下一轮开发计划中。

## 1080P 笔记本显示

v0.9.13 会自动读取可用屏幕区域，避开 Windows 任务栏并进入 compact mode。若本机仍有裁切，请运行：

```bat
python scripts\capture_field_workbench_windows_diagnostics.py --output windows_fit_check
```

把 `screen_diagnostics.json` 和截图用于后续适配。
