# MyGPR v0.8.82 项目元数据与项目设置

## 用途

项目元数据用于描述一个现场勘探项目的工程背景，并写入项目根目录的 `project.json`。这些字段会用于首页、项目管理页、后续空间成果和成果报告。

## 新建项目时可填写

- 项目名称
- 项目编号
- 测区位置
- 项目操作员
- 设备型号
- 坐标系统
- 垂向基准
- 保存目录

## 项目设置

在项目管理页点击“项目设置”，可以修改：项目名称、项目编号、测区位置、项目操作员、设备型号、坐标系统和垂向基准。保存后会立即同步 `project.json`，并刷新首页和项目管理页显示。

## 当前边界

- 项目设置不会改变已经导入的测线矩阵或处理结果。
- 坐标系统和垂向基准目前作为项目元数据保存，后续空间成果和报告导出会继续使用这些字段。
- 厂商格式原生解析仍未完成；DZT / RD3 / DT1 当前仍需转换后导入。
