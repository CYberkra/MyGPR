# MyGPR v0.8.79 项目操作说明

## 新建项目

在“项目管理 → 数据导入与质检”中点击“新建项目”，选择保存目录并输入项目名称。

## 打开项目

点击“打开项目”，选择包含 `project.json` 的 MyGPR 项目目录。

## 导入测线数据

当前正式导入入口支持：

- CSV
- NPY
- NPZ
- H5 / HDF5

导入后，MyGPR 会在项目目录中生成标准化 GPR 数据文件，并同步更新测线清单。

## 尚未直接解码的格式

DZT / RD3 / DT1 等厂商格式当前会被识别，但需要先转换为 CSV / NPY / NPZ / H5 后导入。
