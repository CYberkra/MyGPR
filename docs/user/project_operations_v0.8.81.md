# MyGPR v0.8.81 项目操作说明

## 新建项目

在“项目管理”页点击“新建项目”，填写项目名称、测区位置、操作员和保存目录。软件会创建空正式项目，并生成 `project.json`、`raw/`、`processed/`、`targets/`、`spatial/`、`reports/`、`logs/`。

## 导入测线数据

点击“导入测线数据”后选择文件。导入前会显示预检结果，包括格式、支持状态、矩阵尺寸、测线长度、时间窗和建议。只有预检通过的文件才能继续导入。

当前可直接导入：CSV、TXT、NPY、NPZ、H5、HDF5。

DZT、RD3、DT1 等厂商格式当前只识别并提示转换，不会假装已经完整解码。

## 最近项目

“项目管理”页底部提供最近项目下拉框，可直接选择并打开最近使用的项目。
