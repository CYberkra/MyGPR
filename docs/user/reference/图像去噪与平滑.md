# 高斯平滑与非局部均值去噪

入口：处理页 → 去噪 → **高斯平滑（Gaussian）** / **非局部均值去噪（NLM）**。
两者是对雷达数值矩阵的处理步骤，会生成可追溯的新成果，参数和计算信息随成果保存，
并进入逐步处理结果包。原始输入保留；矩阵尺寸、时间/深度轴和逐道元数据不变。

## 高斯平滑

使用高斯加权平均，时间方向和道间方向分别设置标准差 σ：

- 时间方向 σ：单位是采样点，默认 **0**，不混合相邻时间采样。
- 道间方向 σ：单位是道，默认 **1**；适合先尝试轻度道间平滑。
- 两方向都为 0 时不改变数据。核截断为 4σ，边界使用半采样对称延拓。

计算快，但会削弱高频和小尺度细节。时间方向平滑可能展宽雷达子波；
较大的道间 σ 可能抹平窄异常。道间参数按道序号定义，不代表固定米数，
非等距采集时尤其要注意。

## 非局部均值去噪（NLM）

在搜索邻域内比较二维波形块，以块内均方差 D 计算权重 `exp(-D / h²)`，
再对块中心的**带符号振幅**加权平均。包含自身块，块内采用均匀权重，
本版不做噪声方差扣除，也不要求先取包络。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 强度单位 | 全局 RMS 倍数 | `有效 h = 设置值 × 当前输入矩阵的 RMS`；可切换原始振幅单位 |
| 滤波强度 h | 0.6 | 值越大越平滑，也越可能削弱真实弱反射；0 为不处理 |
| 相似块高度 / 宽度 | 3 采样点 × 5 道 | 两者必须为 1～15 的奇数 |
| 时间 / 道间搜索半径 | 3 采样点 / 5 道 | 默认比较 7×11 个候选块；可设 0～15 |

NLM 比高斯平滑慢，较大的搜索半径会显著增加时间，运行期间支持取消。
默认值只是起点，不是对某一测区的最优参数；建议先裁取代表性的短段对比，
再用于全测线。对比时保持相同色标，并检查反射连续性与原始剖面，不能只看图是否干净。

## 数值与执行约定

- 直接处理浮点雷达振幅，不转成 0～255 灰度图，不额外归一化、截幅或降采样。
- 使用有重叠边界的分块计算；NLM 的 RMS 在全输入范围计算，不随块改变。
- 原始输入包含 NaN/Inf 或超出 float32 范围时明确报错，不静默替换。
- NLM 使用有限支撑的正权卷积计算块距离，避免强直达波使远处弱距离丢失精度。

## 方法依据

- [SciPy gaussian_filter 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.gaussian_filter.html)：分轴标准差、核截断与边界约定。
- [scikit-image NLM 官方文档](https://scikit-image.org/docs/stable/api/skimage.restoration.html#skimage.restoration.denoise_nl_means)：块相似度、强度 h、搜索范围及计算开销。

实现复用已有 SciPy，不增加 scikit-image 依赖；NLM 为上述明确规则的原生实现，
不承诺与 scikit-image 不同权重/边界实现逐位相同。
