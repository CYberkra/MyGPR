# 处理预设档参考

10 个内置预设档（`core/preset_profiles.py`）。`auto` 按数据头自动推荐。CLI 用法见[无界面批处理](../how-to/无界面批处理.md)。

## 通用成像

| 预设档 | 算法序列 |
|---|---|
| `robust_imaging` | set_zero_time → dewow → subtracting_average_2D → fk_filter → sec_gain → svd_subspace |
| `uav_gpr_experience_baseline_v1` | set_zero_time → dewow → subtracting_average_2D → sec_gain → svd_subspace |

## 高质量无人机

| 预设档 | 算法序列 |
|---|---|
| `high_quality_uav_gpr` | set_zero_time → dewow → frequency_filter_1d → motion_compensation_v2 → subtracting_average_2D → wavelet_svd → sec_gain |

含运动补偿与 SVD 小波去噪，适合采集质量不稳定、姿态扰动明显的机载数据。

## 去噪专项

| 预设档 | 算法序列 |
|---|---|
| `hankel_denoise` | set_zero_time → dewow → subtracting_average_2D → fk_filter → sec_gain → hankel_svd |
| `wavelet_2d_denoise` | set_zero_time → dewow → subtracting_average_2D → fk_filter → sec_gain → wavelet_2d |
| `wavelet_svd_denoise` | set_zero_time → dewow → subtracting_average_2D → fk_filter → sec_gain → wavelet_svd |

三者前段一致（矫正/去漂移/背景/FK/增益），仅末端去噪核不同，便于 A/B 对比选择。

## 运动补偿

| 预设档 | 算法序列 |
|---|---|
| `motion_compensation_v1` | trajectory_smoothing → motion_compensation_speed → motion_compensation_attitude → motion_compensation_height |
| `motion_compensation_core_v1` | 同 v1 |
| `motion_compensation_v2` | motion_compensation_v2（一体化核，含振动清理与高度模式） |

## 仿真验证

| 预设档 | 算法序列 |
|---|---|
| `gprmax_impulse_validation` | set_zero_time → dewow → subtracting_average_2D → agcGain → wavelet_svd |

## 覆盖范围

- 波let 去噪需要 PyWavelets（`requirements-core.txt` 已含；缺失时该算法报 ImportError 并提示安装）。
- 每算法的参数 schema 由 `NativeProcessingCatalog` 提供并经 UI/CLI 双侧统一（`backend_api_v1.json` 契约）；AutoTune 候选空间同样受其约束。
