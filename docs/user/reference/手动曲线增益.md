# 手动曲线增益

入口：处理页 → 增益与振幅 → 手动曲线增益 → 参数中的“编辑曲线”。

本方法采用与采集端手动显示增益一致的规则，但在 MyGPR 中实际计算并保存新的处理成果。
原始测线不被覆盖。曲线参数随处理步骤、成果溯源和结果包保存。

曲线横轴为增益 dB，纵轴为当前输入的采样位置百分比。支持 2～32 个节点，首尾固定在
0% 和 100%，增益为 −60～+60 dB。默认五个节点全部为 0 dB，结果与输入相同。
拖动节点或使用数值框调整；双击空白添加，右键节点或 Delete 删除内部节点。
“还原为 0 dB”清零曲线，“应用曲线”更新处理参数，“取消”放弃本次编辑。

## 边调边看

打开曲线编辑器后，左侧调节点，右侧预览当前测线输入的 B-scan。
若前面还有启用的普通滤波、裁剪等步骤，先在后台计算这些步骤的结果，随后缓存该输入；
拖动节点只更新当前手动增益，不反复执行前面的算法。窗口标明输入来源、前置步骤数和完整采样/道数。

- **增益后 / 增益前**：在同一视野、同一色阶下切换对比。
- **色阶默认固定**：避免自动调色抵消增益变化；“按当前图定标”会以当前图重新确定范围，再锁定。
- **全览**：回到完整输入；滚轮和平移可观察局部，调节点保留当前视野。
- 连续拖动期间也会更新最近完成的帧；尚有待更新内容时显示“正在更新”，最后一帧匹配当前曲线后才可应用。

曲线调整是私有草稿，预览不写入成果、不修改原始输入或其他 B-scan。
“应用曲线”只写回此步骤参数，之后运行处理链才生成处理成果；取消不改参数。
切换测线、输入成果、前置步骤或修改当前测线的时间/距离等元数据时，旧预览关闭并失效。

完整预览上限为800万单元，不通过抽道/降采样绕过限制。
前置时深转换、测距重采样、偏移成像可能扩大输出网格，须先运行这些步骤，
再选择它们的成果追加手动曲线增益；不会先分配一个超大网格再截断。

预览与正式算法共用增益计算。输入包含 NaN/Inf 时，预览按完整输入的有限值均值填充并提示，
默认逐步保存执行路径与此一致；关闭逐步保存的历史分块路径可能逐块填充，
对这类输入不能宣称数值完全一致，应先处理无效值。
处理页若采用自动色阶，新成果的明暗可能与固定色阶预览不同，振幅对比应使用相同的色标范围。

相邻节点之间先在 dB 域做线性插值，再按 `振幅倍率 = 10 ** (dB / 20)` 乘入各道。
例如 +20 dB 为 10 倍，−20 dB 为 0.1 倍。保持数据形状、正负极性、坐标轴和道号，
不做归一化、截幅或降采样。过大结果无法用 float32 保存时会报错，须降低增益。

位置以**当前输入**为准：若先做时窗裁剪，0%～100% 对应保留的采样范围；若希望增益始终
对应裁剪前的位置，可把本步骤放在时窗裁剪之前。增益也会放大噪声，不等同于去噪或深度校正。

CLI/处理链方法号为 `manual_gain`，参数 `nodes` 可为节点数组或其 JSON 字符串：

```json
{"method_id":"manual_gain","params":{"nodes":[{"tau":0,"db":0},{"tau":0.5,"db":6},{"tau":1,"db":20}]}}
```

`tau` 是 0～1 的归一化位置，各节点须严格递增。旧有“线性分贝增益”仍保留，用于只需
起止两点的直线曲线；本方法允许设置任意内部节点。
