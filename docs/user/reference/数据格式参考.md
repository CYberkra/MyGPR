# 数据格式参考

九种格式的识别与布局事实。导入操作见[任务指南](../how-to/导入测线数据.md)。

## 支持总表

| key | 显示名 | 扩展名 | 支持级别 |
|---|---|---|---|
| mygpr_csv | MyGPR / matrix CSV | csv, txt | native |
| gprmax_out | gprMax output | out | native |
| numpy_array | NumPy array | npy, npz | native |
| mala_rd | MALÅ RD3/RD7 + RAD | rd3, rd7, rad | native-subset |
| impulseradar_iprb | ImpulseRadar IPRB + IPRH | iprb, iprh | native-subset |
| segy | SEG-Y fixed-length profile | sgy, segy | native-subset |
| envi_bsq | ENVI BSQ DAT/HDR | dat, hdr | native-subset |
| sensors_software_dt1 | Sensors & Software DT1/HD | dt1, hd | native-subset |
| gssi_dzt | GSSI DZT | dzt, dzg | native-subset |

`native`：完整支持。`native-subset`：覆盖常见变体的保守子集（超出子集会明确报错而非误读）。

## 二进制布局速查

**RD3/RD7**：`<i2`/`<i4` 连续逐道；`.rad` 文本头（SAMPLES / TIME WINDOW / DISTANCE INTERVAL / LAST_TRACE）。

**DT1**：无文件头，N ×（128B 道头 + samples×int16）。道头 32 个 float：`[0]` 道号（1 起）、`[1]` 位置、`[2]` 每道采样数、`[7]` 叠加次数。`.hd` 文本头键值（NUMBER OF TRACES / TOTAL TIME WINDOW / STEP SIZE USED / POSITION UNITS…），ft 自动换算 m。

**DZT**：1024B 固定头（小端）。关键字段：`rh_nsamp`（采样数）、`rh_bits`（8/16/32）、`rh_zero`、`rhf_sps/spm/range`、`rh_nchan`。头块数由 `rh_data` 决定；uint8/16 读入后减 2^(bits-1) 转有符号。

**SEG-Y**：3200B 文本头 + 400B 二进制头（sample_interval_us / samples / format code 2/3/5/8）+ N×(240B 道头 + 样本)。

**ENVI BSQ**：`.hdr` 文本键值（samples/lines/bands/data type/interleave/byte order）+ 裸二进制。

**gprMax `.out`**：HDF5；同目录 `.in` 补充道间距。

## 验收资产

格式的正确性由冻结样例保证：`tests/fixtures/vendor_formats_v1/vendor_formats_manifest.json` 登记真实样例（GPRPy GSSI/SnS、segyio F3）与派生样例的 SHA256、二进制布局与交叉验证记录。解码器回归测试即基于此。
