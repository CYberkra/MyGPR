# 短段异常道修补（实验）

方法ID：`short_trace_repair`，实现版本`native-short-trace-2.1`。可在方法库按“短段异常道修补”“坏道插值”搜索。默认自动分窗，区分“跨窗异常候选”和“局部时窗变化”；两者都不是采集坏道诊断。它与隐藏的`trace_qc`整道能量/手动标记方法独立。

## 使用顺序

1. 在原始输入上点击“＋”，从“质量控制”添加“短段异常道修补”，单击链中方法打开参数。保持“仅标记”及“自动分窗”，无需逐文件填写时窗，默认不改变波形。
2. 算法按保存的有效样点序列分成三个不重叠的等比例窗口，所有样点使用一次；均匀采样时对应时间三等分。它不会自动识别直达波、有效回波末端或地层深度。少于12点时仅作局部审阅，不进行整道插补。
3. 确认局部异常确实值得修补后，从对应输入分支以相同参数选择“插补修复”并运行。界面选择项分别保存为内部值`mark`／`interpolate`，旧参数和CLI保持兼容。输出保存为派生成果，原始测线保留。
4. 同时看原始、派生和差图。竖纹变弱不等于恢复了真实反射，也不构成空洞证据。

## 参数与规则

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `mode` | 仅标记（`mark`） | 下拉选择“仅标记”／“插补修复”（`interpolate`），不需输入英文 |
| `window_mode` | 自动分窗（`auto`） | 可选“手动时窗”（`manual`）、“旧版全窗（对照）”（`full`） |
| `window_traces` | 31 | 逐时点中位参考的道数，3–301的奇数，边缘reflect；参考只用于检测 |
| `robust_z` | 8 | 每个时间窗先计算各道相对局部参考的RMS差，再用全线这些RMS差的中位数＋该倍数×1.4826×MAD作阈值；不是每道各自计算31道MAD。零MAD按零处理，不加入固定幅度单位的下限；倍数8不是误报概率或8σ置信保证 |
| `time_windows_ns` | 空 | 高级项，仅手动方案生效。自动或旧全窗方案忽略保留的文本，并记录是否忽略 |
| `max_run_traces` | 4 | 仅允许1–4道的短段；较长段保留原值并标记未插补 |

手动时间窗必须位于有效时间轴内。浮点轴保存为float32时，按存储精度识别实际边界样点；共享端点只归后窗使用。不把样点序号当ns，不用文件名推断深度。没有时间标定时，可按样点自动分窗或选择旧版全窗，不能使用手动ns时窗。

自动方案在缺少时间标定时按样点分窗，省略ns坐标；提供或重建的时间轴须有限、严格递增。手动方案必须有有效时间轴，可在高级项填写如`0:100;100:200;250:850`（900ns记录示例，不是通用默认）。手动窗排序后不得实质重叠；共享边界样点只归后窗，去重后每窗至少4点。至少两个独立手动窗全部超阈值才列跨窗候选，单窗仅作局部审阅。手动两窗可用于8点记录；少于12点的限制专指自动方案。旧版全窗是显式的一窗兼容例外，不能称作跨窗证据。

旧参数未包含`window_mode`时，非空手动窗仍推断为手动，空文本采用新的自动默认；编辑旧参数也保留此规则。要重放1.x的空窗全样点判断，必须明确选择“旧版全窗（对照）”。已保存旧成果保持不变。

输入采用项目float32实数矩阵（样点×道），不静默丢弃复数分量或填充NaN/Inf。检测按样点分块计算局部参考，支持协作取消。本方法没有自动加入AutoTune。

连续候选段只有在长度不超过上限、且两端均有未标记参考道时才插补。边缘不外推；已被`trace_qc`标记、尚未处理或此前已插补的参考道也不作为新的可信端点。每条候选道由两端原始输入道按道号作线性插值。道数、时间轴、原始ID和传感器序列不因插补改变；未插补的float32样点保持原值。

各窗独立计算稳健阈值。自动三窗全部超阈值才列跨窗候选；只在部分窗超阈值的道列为局部变化，不整道插补。本步及输入成果中的局部标记也不能作插补端点；因此跨窗候选数不等于实际插补数。

## 掩码与后续处理

成果逐道保存：

- `short_trace_candidate_mask`：本步检出的候选道。
- `short_trace_local_change_mask`：本步仅部分窗口异常的局部变化道；不并入整道未插补历史。父成果保留先前分类。
- `short_trace_zero_mask`：本步输入的所有保存样点都精确为零的道，独立数据质量类别；不计入统计候选或局部变化。成功插补后仍保留本步输入原因；重采样传播表示受影响来源，不表示输出仍整道全零。
- `short_trace_repaired_mask`：本分支已经插补的道，保留先前步骤的插补记录。
- `short_trace_unresolved_mask`：沿分支保留的未插补候选。改变时窗或阈值后不再检出，也不自动清除历史标记；只有明确成功插补相应位置才清除。`mark`模式下本步统计候选及整道全零全部加入这一类，计数包含保留的历史位置。

B-scan红色覆盖层显示跨窗候选、旧全窗候选、历史未插补、已插补及输入整道全零位置；黄色显示局部时窗变化。覆盖只指出道号，不代表整个时间轴都有异常。当前局部类可优先用黄色显示历史未插补位置，但不会清掉历史掩码；当前跨窗、已有QC坏道和已插补记录保持红色优先。质检列表区分类别。新掩码不写进`trace_qc_bad_mask`，避免影响其他置零/删除选择。

视图右上角“…”菜单或图内右键菜单中的“显示异常道标记”勾选项控制覆盖层显隐，默认显示；画布上没有常驻开关，也不增加工具栏。普通与全屏视图使用同一设置。该选择是全局显示偏好，同步当前窗口的其他B-scan，切换数据和重新启动后保持。关闭只隐藏标记，不删除掩码、不改变波形、不触发处理或重新加载预览；再次打开可恢复审阅位置。

从旧标记成果继续处理会保留历史待审位置，红色不一定来自本次分类。比较新旧判据时宜都从原始输入运行，再查看各步的分类和历史掩码。

后续等距重采样时，只要输出道含有任一标记输入道的非零插值贡献，就保留该标记；精确落在未标记输入位置时不扩散邻道标记。裁剪等操作仍按同一几何映射传递元数据。

## 科学解释范围

这个方法提高局部道间连续性，不保证重建未知真实信号。单道或少道范围内的真实目标可能被插值覆盖；应保留原始输入并检查掩码和被移除的差值。多窗共同判据也不能证明某一候选的成因。对已知正常道做遮挡回填，只能估计这些区段的插值误差，不能代替异常道真值或给出目标损伤率。

受控反例表明：全样点检测可能标记真实局部波包、陡倾事件和双曲线事件；三窗共同检测保护了本次单个晚时波包，但跨三个时间窗同时出现的真实局部波包仍可被检出并抹除。即便已知正确的坏道位置，线性插补也可能改变陡倾事件的波形和峰值时刻。较长连续坏段占据31道参考的一半以上时，还可能根本检不出来。因此本方法保持实验标记，适合作为人工审阅后的小范围修补工具，不适合无监督批量恢复。详见[复审记录](../../artifacts/2026-10-30-short-trace-review.md)。

2.1在统计判断前独立检查整道数据：只有所有保存样点都精确为零才列入全零质量类别，无幅度下限，不以某个时窗安静判坏。全零道从统计候选和局部类移除，但统计参考、RMS总体和阈值不变。默认只标记；明确选插补后仍需独立窗充足、短段、两端有效参考，端部不外推。全零输入也不能当健康插补参考。NaN/Inf会中止处理并报告全部受影响道号，不填充、不保存派生波形。G5_06末尾457、458道现已单列为全零质量问题并保留原值；源容器对象异常仍需单独核查。见[2.1修正记录](../../artifacts/2026-10-30-short-trace-quality.md)。

## 本地验证入口

从仓库根目录执行，输出目录须为空或不存在：

```powershell
.\.venv\Scripts\python.exe -m scripts.validate_short_trace_repair --source '<原始H5>' --output '<新的本地目录>' --time-windows-ns '0:100;100:200;250:850'
```

脚本创建独立临时项目及独立设置，验证默认标记不改原始、显式插补、正常道遮挡、导出原始/派生结果包并重新导入核对矩阵/时间轴/掩码。原始文件以处理前后SHA256核对。脚本不上传文件，也不接管正在运行的真实项目。
