# 项目目录与文件位置

## 新项目结构

```text
<项目目录>/
├── project.json                    # 项目身份、设置和兼容清单
├── catalog.sqlite                  # 测线、成果目录、分支和谱系
├── data/lines/<测线>.h5             # 原始标准化矩阵与轴
├── data/lines/<测线>.artifacts/     # 处理矩阵 sidecar（按存储策略使用）
├── raw/<测线>/                     # 源文件副本、导入清单、轨迹与质检旁文件
│   └── sensors/                    # 同步轨迹、元数据、来源
├── processed/<测线>/               # 成果描述符、参数与处理清单
├── targets/                        # 目标标注兼容文件
├── metadata/                       # 界面标注等元数据
├── interpretations/                # 标注历史版本
├── spatial/                        # 正式空间成果版本
├── reports/                        # 报告包
├── exports/                        # 外部导出
├── cache/                          # 暂存与预览
├── logs/field_workbench.log         # 项目操作日志
└── .mygpr.lock                     # 项目锁
```

旧项目可继续使用 JSON/NPY/NPZ 布局；现行协议见[Hybrid Store](../../developer/HYBRID_PROJECT_STORE_V1.md)。项目打开时不要单独复制 SQLite、WAL/SHM 或某个 HDF5 文件，使用[备份功能](../how-to/生成报告与备份.md)生成一致快照。

## 用户级位置

| 内容 | 位置 |
| --- | --- |
| Windows 应用日志 / 崩溃转储 | `%LOCALAPPDATA%/MyGPR/output/logs/` |
| 无 LOCALAPPDATA 时的日志回退 | `~/MyGPR/output/logs/` |
| 设置 | `~/MyGPR/config/settings.json` |
| 默认备份根 | `~/MyGPR_Backups/<项目目录名>/`，可用 `MYGPR_BACKUP_ROOT` 覆盖 |
| 默认项目根 | `~/Documents/MyGPRProjects/`，设置页可改 |
| 离屏截图 | 系统临时目录 `mygpr_shots/`，可用 `MYGPR_SMOKE_SHOTS_DIR` 覆盖 |
| 证据导出 | 优先 `MYGPR_EVIDENCE_ROOT`，其次现存的仓库同级 `MyGPR-Evidence/`，再回退用户应用数据目录 |

实际来源为 `core.app_paths`、`ui.constants.SETTINGS_FILE` 和 `app_qt.SMOKE_SHOTS_DIR`。任务中心保留后台作业状态；反馈问题时附上任务错误和相关日志。
