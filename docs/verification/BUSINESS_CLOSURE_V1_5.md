# MyGPR 项目—处理—标注业务闭环 V1.5

日期：2026-07-14  
应用版本：MyGPR v0.9.28  
实施轮次：Business Closure V1.5

## 目标

在不改变五页 Golden Reference 外观的前提下，打通以下可恢复业务链：

```text
项目创建/打开
→ 测线处理草稿
→ 应用与重算
→ 正式处理版本
→ 基覆界面标注草稿
→ 已确认标注 revision
→ 关闭并重新打开项目
→ 恢复处理草稿与标注恢复点
```

## 已完成

### 项目

- 新建项目允许所有业务字段留空。
- 空名称自动生成 `未命名项目_YYYYMMDD_HHMMSS`。
- 空目录默认使用用户文档下的 `MyGPR Projects`。
- 项目切换前自动保存当前测线处理草稿并关闭旧会话。
- 空项目不再伪造 L01 测线或标注内容。

### 测线处理

- 新增 `mygpr.processing_draft.v1` 持久化草稿格式。
- 每条测线独立保存输入版本、步骤、参数、启停状态和当前步骤。
- 重新打开项目或切回测线时，从原始数据重放处理链并恢复完整结果。
- 处理步骤支持添加、删除、启用/停用、前移、后移。
- 修改中间步骤后，从最早变更位置原子重算后续链。
- 处理失败或取消时保留上一份完整结果。
- 正式处理版本继续采用不可变产物；修正同秒产物索引排序，优先选择最新时间戳产物。
- 横向处理链改为真实会话状态，不再显示固定演示节点。

### 界面标注

- 优先读取 `annotations/recovery/<line>_basal_interface_recovery.json` 恢复未保存草稿。
- 标注编辑继续采用原子恢复点写入。
- 已确认标注修改后继续创建新 revision，不覆盖既有正式版本。
- 空项目显示明确的“暂无基覆界面标注”状态。
